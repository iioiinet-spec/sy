00 / OVERVIEW

완성작이 갖춰야 할 모습

최종 프로젝트는 지금까지 만든 모든 시스템이 서로 연결되어 하나의 흐름으로 이어져야 완성이에요. 타이틀에서 시작해서, 펫을 키우고, 상점에서 아이템을 사고, 미니게임으로 골드를 벌고, 자동으로 저장되고, 친밀도에 따라 다른 엔딩을 보는 것까지 — 이 모든 게 끊김 없이 이어지는 게 목표입니다.

04 / GRADUATION MISSIONS

졸업 미션 — 나만의 개성 더하기

기본 완성작에서 한 걸음 더 나아가고 싶다면, 아래 아이디어 중 하나를 골라 나만의 버전으로 발전시켜보세요.

01

펫 종류 선택 기능 쉬움

타이틀 장면에 강아지·고양이·토끼 중 하나를 고르는 버튼을 만들어, 선택한 펫 모양이 게임 내내 유지되게 해보세요.

▸ 힌트 보기
문자 변수 "펫종류" 추가 → 선택 버튼 클릭 시 펫종류를 "강아지"로 정하기 →
펫 오브젝트 시작 시: 만약 <펫종류 = "강아지"> 이라면 모양을 강아지로 바꾸기
02

미니게임 랭킹 리스트 보통

클라우드 리스트에 최고 점수 5개를 저장해, 새 기록이 나올 때마다 순위표가 갱신되도록 만들어보세요. (배웠던 리스트 + 클라우드 저장의 결합!)

▸ 힌트 보기
클라우드 리스트 "랭킹"에 점수 추가 → 정렬 함수로 내림차순 정렬 →
항목 수가 5개를 넘으면 가장 낮은 점수 삭제
03

파이썬 모드로 미니게임 하나 직접 짜보기 도전

완성된 블록 프로젝트에서 사과 낙하 로직 하나를 코드변환으로 확인한 뒤, 같은 동작을 텍스트 코딩으로 처음부터 다시 작성해보세요.

▸ 힌트 보기
for 반복문으로 낙하 위치 갱신 → if 문으로 바구니 충돌 판정 →
함수로 "사과 하나 생성하기" 로직을 감싸서 재사용해보세요.
