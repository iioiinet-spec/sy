00 / OVERVIEW

이 실습에서 배우는 것

하나의 게임을 다섯 개 오브젝트가 나눠서 만듭니다. 각 오브젝트는 독립적으로 움직이지만, 변수로 상태를 공유하고 신호로 서로에게 "지금이야!"를 알려주며 협력해요.

01

변수로 상태 관리하기

친밀도·배부름·청결도·골드처럼 시간에 따라 변하는 값을 변수에 저장하고 화면에 보여줍니다.

02

신호로 오브젝트 연결하기

버튼을 눌렀을 때 펫이 반응하도록, 서로 다른 오브젝트끼리 신호를 주고받는 구조를 익힙니다.

03

복제본으로 여러 개 만들기

사과 하나의 코드로 수십 개의 사과를 계속 만들어내고, 각자 알아서 떨어지고 사라지게 합니다.

3. 미니게임 바구니 (플레이어) 오브젝트

"남은 시간 번 반복하기"는 변수 값(20)을 반복 횟수로 그대로 쓰는 트릭이에요. 반복 안에서 남은 시간을 직접 -1 하고 있으므로, 화면의 카운트다운 숫자와 실제 반복 횟수가 항상 같게 유지됩니다.

복제본은 "붕어빵 틀" 같은 존재예요. 원본 오브젝트 하나의 코드로 똑같은 사과를 계속 찍어내고, 각 복제본은 독립적으로 자기만의 위치·속도를 가지고 떨어집니다. 화면 아래로 사라지거나 바구니에 닿으면 반드시 삭제해야 복제본이 무한히 쌓이지 않아요.

04 / MISSIONS

추가할 부분 — 확장 미션

기본 게임이 완성됐다면, 아래 미션을 하나씩 도전하며 블록을 스스로 확장해보세요. 힌트를 누르면 필요한 블록 아이디어가 나와요.

01

썩은 사과 오브젝트 추가하기 쉬움

사과 오브젝트를 복제해서 색이 다른 "썩은 사과"를 만들고, 바구니에 닿으면 점수가 아니라 친밀도가 줄어들게 해보세요.

▸ 힌트 보기
복제본이 생겼을 때 → 계속 반복하기 → y좌표 -5만큼 바꾸기 →
만약 <바구니에 닿았는가?> 이라면 → 친밀도에 -10만큼 더하기 → "윽, 상했어!" 말하기 → 이 복제본 삭제하기
02

난이도 상승 만들기 보통

남은 시간이 줄어들수록 사과가 떨어지는 간격이 점점 짧아지도록 만들어보세요. 처음엔 여유롭다가 후반에는 정신없이 쏟아지게요.

▸ 힌트 보기
"0.5~1.5초 사이 무작위 수 기다리기" 대신, 남은 시간이 클 때는 넓은 범위(1~2초), 남은 시간이 작을 때는 좁은 범위(0.2~0.5초)를 쓰도록
만약 <남은 시간 > 10> 판단문으로 두 가지 기다리기 블록을 나눠보세요.
03

상점 오브젝트 만들기 보통

골드로 살 수 있는 "미니게임 시간 연장권"을 만들어보세요. 클릭하면 골드 30을 쓰고, 다음 미니게임의 시작 시간이 20이 아니라 25가 됩니다.

▸ 힌트 보기
새 변수 "시간연장"을 만들고 기본값 0으로 설정 →
상점 클릭 시: 만약 <골드 > 29> → 골드 -30, 시간연장을 5로 정하기 →
바구니 오브젝트의 "남은 시간을 20으로 정하기"를 "20 + 시간연장으로 정하기"로 수정
04

레벨업 시스템 도전

친밀도가 100이 되면 "레벨"이라는 새 변수가 +1 되고, 친밀도는 다시 0으로 초기화되도록 만들어보세요. 레벨마다 펫의 대사가 달라지면 더 좋아요.

▸ 힌트 보기
새 변수 "레벨"을 만들고 시작 시 1로 정하기 →
먹이주기·씻기기 신호 블록 끝에 "만약 <친밀도 > 99> 이라면" 판단 추가 →
레벨에 +1 더하기, 친밀도를 0으로 정하기, "레벨업!" 2초 동안 말하기
