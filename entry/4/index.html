00 / OVERVIEW

일반 변수 vs 클라우드 변수

일반 변수는 프로그램이 꺼지는 순간 값이 사라져요. 클라우드 변수는 로그인된 엔트리 계정에 값을 저장해서, 브라우저를 껐다 켜거나 다른 컴퓨터에서 접속해도 이전 값 그대로 이어집니다.

01

클라우드 변수 만들기

변수 만들기 창에서 "클라우드 변수로 사용하기"를 체크해 저장용 변수를 준비합니다.

02

불러오기 / 저장하기 흐름 설계

시작할 때 클라우드 값을 로컬로 복사하고, 저장 시점에 로컬 값을 클라우드로 다시 복사합니다.

03

저장 타이밍 다루기

매 프레임마다 저장하지 않고, 특정 순간에만 저장해 서버 요청을 아끼는 습관을 익힙니다.

⚠️

클라우드 변수는 로그인해야 동작해요. 로그인하지 않은 상태(오프라인 실행 포함)에서는 값이 저장되지 않으니, 실습 시 반드시 엔트리 계정으로 로그인한 뒤 확인하세요.

01 / SETUP

로컬 변수 & 클라우드 변수 짝 짓기

플레이 중에는 빠른 로컬 변수를 쓰고, 저장할 때만 같은 이름의 클라우드 변수로 값을 옮기는 방식을 씁니다. 이렇게 하면 게임 도중 값이 계속 바뀌어도 서버에는 필요할 때만 전송돼요.

클라우드 변수는 처음 만들면 값이 0이에요. "저장레벨 = 0"인지 확인하면 이 사람이 완전 신규 유저인지, 저장 기록이 있는 유저인지 구분할 수 있습니다.

⏱️

클라우드 변수는 값이 바뀔 때마다 서버로 전송돼요. 매 프레임(초당 60번)처럼 너무 자주 값을 바꾸면 요청이 몰려서 저장이 씹히거나 지연될 수 있어요. "친밀도가 바뀔 때마다"가 아니라 30초에 한 번, 또는 미니게임이 끝났을 때처럼 의미 있는 시점에만 저장하는 습관을 들이세요.

04 / MISSIONS

확장 미션

기본 저장/불러오기를 익혔다면, 아래 미션으로 더 실전적인 저장 시스템을 만들어보세요.

01

미니게임 종료 시 자동 저장 쉬움

30초 반복 저장 대신, "미니게임 종료" 신호를 받았을 때도 "게임 저장" 신호를 함께 보내도록 만들어보세요.

▸ 힌트 보기
아무 오브젝트에 추가:
[시작] 미니게임 종료 신호를 받았을 때 → [시작] 게임 저장 신호 보내기
02

마지막 저장 시각 표시 보통

클라우드 변수 "저장시각"(문자)을 추가해서, 저장할 때마다 현재 시간을 기록하고 화면에 "마지막 저장: OO시 OO분"을 보여주세요.

▸ 힌트 보기
[계산] 현재 시간(시)/현재 시간(분) 블록을 문자로 합치기 →
저장시각을 (시 + "시 " + 분 + "분")으로 정하기 → 게임 저장 신호에 포함
03

클라우드 리스트로 업적 기록하기 도전

미니게임에서 신기록을 세울 때마다 클라우드 리스트 "최고기록"에 점수를 추가해서, 누적 기록을 여러 개 저장해보세요.

▸ 힌트 보기
리스트 만들기에서도 "클라우드 리스트로 사용"을 체크할 수 있어요 →
결과창 띄우기 신호를 받았을 때 → 최고기록 리스트에 미니게임 점수 항목 추가하기
