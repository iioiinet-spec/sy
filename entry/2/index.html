00 / OVERVIEW

변수만으로는 부족한 이유

아이템이 4개면 변수 4개, 40개면 변수 40개를 만들어야 할까요? 리스트는 순서가 있는 값들의 묶음이에요. 상점 아이템이 늘어나도 변수를 추가할 필요 없이 리스트에 값만 추가하면 됩니다.

01

리스트 만들고 값 채우기

상점에 팔 아이템 이름과 가격을 각각 리스트에 순서대로 저장합니다.

02

인덱스로 항목 다루기

"n번째 항목"으로 특정 위치의 값을 읽고, 구매 시 인벤토리 리스트에 새 값을 추가합니다.

03

반복문으로 전체 순회하기

리스트의 항목 수만큼 반복하며 인벤토리 전체를 화면에 표시합니다.

1. 상점 진열대 오브젝트

시작 시 리스트를 채우고, 화살표로 아이템을 넘겨봄
블록 1 · 상점 리스트 초기화
시작장면이 시작되었을 때
자료상점이름 리스트의 모든 항목 삭제하기
자료상점가격 리스트의 모든 항목 삭제하기
자료상점이름에 "고급사료" 항목 추가하기
자료상점가격에 30 항목 추가하기
자료상점이름에 "장난감공" 항목 추가하기
자료상점가격에 25 항목 추가하기
자료상점이름에 "향기샴푸" 항목 추가하기
자료상점가격에 20 항목 추가하기
자료진열 번호를 1로 정하기
블록 2 · 다음 아이템 보기 (화살표 클릭)
시작오브젝트를 클릭했을 때
판단만약 < 진열 번호 < 상점이름의 항목 수 > 이라면
자료진열 번호에 +1만큼 더하기
[아니면]
자료진열 번호를 1로 정하기
생김새(상점이름의 진열 번째 항목)를 말하기
📦

"리스트의 항목 수" 블록은 지금 리스트에 값이 몇 개 들어있는지 세어줘요. 아이템을 나중에 추가·삭제해도 이 블록 덕분에 "진열 번호"가 범위를 벗어나지 않도록 안전하게 순환시킬 수 있습니다.

💰

2. 구매 버튼 오브젝트

진열 번호에 해당하는 가격을 확인하고 인벤토리에 추가
시작오브젝트를 클릭했을 때
판단만약 < 골드 > (상점가격의 진열 번째 항목) > 이라면
[참]
자료골드에 -(상점가격의 진열 번째 항목)만큼 더하기
자료인벤토리에 (상점이름의 진열 번째 항목) 항목 추가하기
생김새"구매 완료!"를 1초 동안 말하기
시작인벤토리 갱신 신호 보내기
[거짓]
생김새"골드가 부족해요!"를 1초 동안 말하기
💡

가격을 변수가 아니라 "상점가격의 진열 번째 항목"으로 바로 계산에 넣을 수 있어요. 값을 따로 변수에 옮겨 담지 않아도, 리스트 블록 자체가 값처럼 동작합니다.

🎒

3. 인벤토리 표시 오브젝트

리스트 전체를 반복문으로 순회하며 화면에 출력
시작인벤토리 갱신 신호를 받았을 때
자료표시글을 ""(빈 문자열)로 정하기
흐름인벤토리의 항목 수 번 반복하기
자료표시글에 (인벤토리의 반복 인덱스 번째 항목) 이어붙이기
자료표시글에 ", " 이어붙이기
생김새표시글을 2초 동안 말하기
🔁

"리스트의 항목 수 번 반복하기"는 리스트를 처음부터 끝까지 훑는 가장 기본적인 패턴이에요. 반복할 때마다 인덱스가 1씩 자동으로 늘어난다고 생각하면, "N번째 항목"과 결합해 전체 목록을 한 줄씩 꺼내올 수 있습니다.

04 / MISSIONS

확장 미션

리스트 기본기를 익혔다면, 아래 미션으로 더 실전적인 시스템을 만들어보세요.

01

같은 아이템 중복 구매 막기 쉬움

이미 인벤토리에 있는 아이템은 다시 살 수 없도록, 구매 전에 리스트를 검사해보세요.

▸ 힌트 보기
구매 버튼 클릭 시 조건 앞에 하나 더 추가:
만약 <인벤토리에 (상점이름의 진열 번째 항목) 값이 포함되어 있는가?> 이라면 → "이미 가지고 있어요" 말하기
아니면 → 기존 구매 로직 실행
02

아이템 되팔기(판매) 기능 보통

인벤토리의 아이템을 클릭하면 구매가의 절반을 돌려받고 리스트에서 삭제되게 만들어보세요.

▸ 힌트 보기
인벤토리 항목 클릭 시: 골드에 (해당 가격 ÷ 2)만큼 더하기 →
인벤토리 리스트에서 (해당 항목의 위치)번째 항목 삭제하기 → 인벤토리 갱신 신호 보내기
03

가격순 정렬 진열대 도전

상점가격 리스트를 기준으로 저렴한 순서대로 아이템이 보이도록 정렬해보세요. (버블 정렬: 두 항목씩 비교하며 자리를 바꾸는 반복문)

▸ 힌트 보기
이중 반복문으로 상점가격의 i번째와 i+1번째를 비교 →
i번째가 더 크면 두 리스트(상점가격, 상점이름)에서 동시에 값 바꾸기 (위치를 맞춰서!)
