00 / OVERVIEW

장면(Scene)이란?

장면은 화면 전체를 통째로 바꾸는 단위예요. 각 장면은 자기만의 오브젝트 목록을 가지지만, 변수는 모든 장면에서 공유됩니다. 이 성질 덕분에 "게임 장면에서 쌓은 친밀도 값을 결과 장면에서 그대로 읽어서" 어떤 엔딩을 보여줄지 결정할 수 있어요.

01

장면 여러 개 구성하기

타이틀·게임·엔딩 장면을 각각 만들고, 장면마다 필요한 오브젝트만 배치합니다.

02

장면 시작하기로 이동하기

버튼 클릭이나 조건 충족 시 다른 장면으로 화면 전체를 전환합니다.

03

변수 값으로 엔딩 분기하기

결과 장면에 도착하기 전, 판단 블록으로 친밀도 값을 확인해 어느 엔딩 장면으로 갈지 결정합니다.

01 / SETUP

장면 · 변수 설계하기

엔트리 화면 좌측 장면 탭에서 "+" 버튼으로 장면 5개를 추가하세요.

1. 타이틀 시작 버튼
2. 펫 키우기 기존 실습 내용
3. 엔딩A · 베스트프렌드 친밀도 70 초과
4. 엔딩B · 성장 중 친밀도 30~70
5. 엔딩C · 다음에 또 만나 친밀도 30 미만
친밀도 장면이 바뀌어도 값 유지
결과 확인
🗂️

오브젝트는 장면마다 독립적이에요. "타이틀 배경"은 타이틀 장면에만 있으면 되고, 펫 캐릭터를 다시 그릴 필요 없이 펫 키우기 장면에만 배치하면 됩니다. 반면 변수는 전역이라 장면이 바뀌어도 값이 그대로 이어져요.

02 / SCENE CODE

장면별 코드

"장면 시작하기"와 "장면이 시작되었을 때"는 모두 ■시작 카테고리에 있어요.

SCENE 1 · 타이틀
🏠

시작 버튼 오브젝트

클릭하면 펫 키우기 장면으로 이동
시작오브젝트를 클릭했을 때
자료친밀도를 50으로 정하기
시작"펫 키우기" 장면 시작하기
🔁

타이틀에서 친밀도를 매번 50으로 초기화해두면, 플레이어가 "처음부터 다시하기"를 할 때마다 이전 기록이 남아있지 않고 깨끗하게 새로 시작할 수 있어요.

SCENE 2 · 펫 키우기
🐾

결과 확인 버튼 오브젝트

일정 시간이 지나거나 버튼을 누르면 친밀도로 엔딩 분기
시작오브젝트를 클릭했을 때
판단만약 < 친밀도 > 70 > 이라면
시작"엔딩A" 장면 시작하기
[아니면 만약]
판단만약 < 친밀도 > 29 > 이라면
시작"엔딩B" 장면 시작하기
[아니면]
시작"엔딩C" 장면 시작하기
🎯

판단을 위→아래 순서로 겹쳐 쌓으면, 친밀도 구간마다 다른 장면으로 흩어지는 분기 구조가 만들어져요. 구간이 겹치지 않도록 70 초과 / 30~70 / 30 미만처럼 경계를 명확히 나누는 게 핵심입니다.

SCENE 3, 4, 5 · 엔딩 A / B / C
🎞️

엔딩 화면 오브젝트 (엔딩마다 각각 배치)

도착한 장면에 맞는 대사를 보여주고 처음으로 돌아가는 버튼 제공
엔딩A 장면 예시
시작장면이 시작되었을 때
생김새"우리는 베스트프렌드가 됐어요! 친밀도 " + 친밀도를 말하기
시작"처음으로" 버튼을 클릭했을 때
시작"타이틀" 장면 시작하기
📝

세 엔딩 장면 모두 구조는 똑같고 대사·이미지만 달라요. "장면이 시작되었을 때" 안에서 도착 당시의 친밀도 값을 그대로 보여줄 수 있는 것도, 변수가 장면을 넘어 유지되기 때문입니다.

03 / TRY IT

라이브 시뮬레이터 — 장면을 직접 넘겨보기

휴대폰 화면처럼 생긴 아래 미리보기에서 실제 장면 전환 흐름을 체험해보세요. 친밀도 값에 따라 도착하는 엔딩이 달라집니다.

04 / MISSIONS

확장 미션

기본 장면 흐름을 만들었다면, 아래 미션으로 더 풍부한 스토리 구조를 만들어보세요.

01

로딩 화면 장면 추가하기 쉬움

타이틀과 펫 키우기 장면 사이에 "로딩중" 장면을 하나 끼워, 1초 대기 후 자동으로 다음 장면으로 넘어가게 만들어보세요.

▸ 힌트 보기
[시작] 장면이 시작되었을 때 → [흐름] 1초 기다리기 → [시작] "펫 키우기" 장면 시작하기
02

이어하기 / 처음부터 분리하기 보통

타이틀 장면에 버튼 두 개를 만들어, "이어하기"는 클라우드 변수를 불러오고 "새로 시작"은 친밀도를 50으로 초기화하도록 나눠보세요.

▸ 힌트 보기
이어하기 버튼: 친밀도를 저장친밀도로 정하기 → "펫 키우기" 장면 시작하기
새로 시작 버튼: 친밀도를 50으로 정하기 → "펫 키우기" 장면 시작하기
03

숨겨진 엔딩 추가하기 도전

친밀도뿐 아니라 골드도 200 이상이면 "엔딩D · 부자 펫주인"이라는 숨겨진 엔딩으로 가도록, 분기 조건 맨 앞에 새 판단을 추가해보세요.

▸ 힌트 보기
결과 확인 버튼 코드 맨 위에 추가:
만약 <골드 > 199> 이라면 → "엔딩D" 장면 시작하기
아니면 만약 <친밀도 > 70> ... (기존 조건 이어서)
