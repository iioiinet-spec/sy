반복되는 코드를 내 블록 하나로

펫에게 먹이를 줄 때도, 아이템을 사용할 때도 "능력치 바꾸고 + 말풍선 띄우기" 패턴이 계속 반복됐죠. 이번엔 이 패턴을 나만의 블록(함수)으로 한 번만 정의하고, 필요할 때마다 값만 바꿔서 호출해봅니다.

00 / OVERVIEW

왜 함수가 필요할까요?

코드가 복사·붙여넣기로 여러 곳에 퍼져있으면, 나중에 말풍선 표시 시간을 2초에서 1.5초로 바꾸고 싶을 때 모든 오브젝트를 일일이 찾아 고쳐야 해요. 함수로 묶어두면 정의부 한 곳만 수정하면 호출하는 모든 곳에 자동으로 반영됩니다.

01

나만의 블록 정의하기

매개변수(입력값 자리)를 가진 새 블록을 직접 만들어봅니다.

02

여러 곳에서 호출하기

같은 함수를 먹이주기·씻기기·아이템 사용 등 다양한 상황에서 값만 바꿔 재사용합니다.

03

판단이 들어간 함수 만들기

매개변수 값에 따라 함수 안에서 다른 변수를 바꾸는 분기 로직을 설계합니다.

01 / HOW-TO

나만의 블록 만드는 방법

엔트리 블록 팔레트 맨 아래 [함수] 카테고리에서 시작해요.

STEP 1

블록 팔레트에서 [함수] 카테고리 클릭 → "블록 만들기" 버튼 선택

STEP 2

함수 이름 입력 (예: 효과주기) → 필요한 매개변수를 드래그로 추가 (문자/숫자/판단 값)

STEP 3

매개변수 이름 지정 (예: 종류, 수치, 대사) → 확인 누르면 정의 블록이 생성됨

STEP 4

정의 블록 아래에 실제 실행할 코드를 조립 → 다른 블록 꾸러미에서 함수를 가져와 호출

⚠️

엔트리 함수의 매개변수는 값만 전달할 수 있어요 (숫자·문자·참거짓). "이 변수를 바꿔줘"처럼 변수 자체를 통째로 넘길 순 없어서, 아래 예시처럼 "종류"를 문자로 받고 함수 안에서 판단 블록으로 어떤 변수를 바꿀지 결정하는 패턴을 씁니다.

1. 효과주기 함수 — 능력치 변화 + 말풍선

매개변수 3개: 종류(문자) · 수치(숫자) · 대사(문자)
함수 정의
함수 정의: 효과주기 종류 수치 대사
판단만약 < 종류 = "친밀도" > 이라면
자료친밀도에 수치만큼 더하기
판단만약 < 종류 = "배부름" > 이라면
자료배부름에 수치만큼 더하기
판단만약 < 종류 = "청결도" > 이라면
자료청결도에 수치만큼 더하기
생김새대사를 2초 동안 말하기
호출 예시 — 오브젝트별로 값만 바꿔서 재사용
시작먹이주기 신호를 받았을 때
함수효과주기 "배부름" 20 "냠냠! 맛있어!"
시작씻기기 신호를 받았을 때
함수효과주기 "청결도" 30 "개운하다!"
시작아이템 사용 신호를 받았을 때
함수효과주기 "친밀도" 15 "신난다!"
♻️

세 신호 모두 다른 상황이지만 같은 함수를 호출해요. 말풍선 표시 시간이나 로직을 바꾸고 싶으면 효과주기 정의부 한 곳만 고치면 세 곳 모두에 적용됩니다.

2. 골드충분한가 함수 — 값을 돌려주는 판단형 함수

매개변수 1개: 가격(숫자) → 참/거짓을 반환
함수 정의 (판단값을 사용함에 체크)
함수 정의(판단): 골드충분한가 가격
함수판단 값을 < 골드 >= 가격 > 으로 정하기
호출 예시
시작구매 버튼을 클릭했을 때
판단만약 < 골드충분한가 (상점가격의 진열 번째 항목) > 이라면
자료골드에 -(상점가격의 진열 번째 항목)만큼 더하기
🧠

이 함수는 값을 바꾸지 않고, 조건이 참인지 거짓인지만 계산해서 돌려줘요. 이렇게 "판단 결과를 돌려주는 함수"를 만들면 복잡한 조건식을 함수 이름 하나로 깔끔하게 표현할 수 있습니다.

04 / MISSIONS

확장 미션

함수의 기본기를 익혔다면, 아래 미션으로 더 안전하고 똑똑한 함수를 만들어보세요.

01

0~100 범위 벗어나지 않게 막기 쉬움

효과주기 함수 안에서 값을 더한 뒤, 100을 넘으면 100으로, 0보다 작으면 0으로 강제로 맞춰보세요.

▸ 힌트 보기
각 판단 블록 안, 변수에 더하기 다음 줄에 추가:
만약 <배부름 > 100> 이라면 → 배부름을 100으로 정하기
만약 <배부름 < 0> 이라면 → 배부름을 0으로 정하기
02

소리까지 재생하는 매개변수 추가 보통

효과주기 함수에 "소리이름"(문자) 매개변수를 하나 더 추가해서, 호출할 때마다 다른 효과음이 나도록 만들어보세요.

▸ 힌트 보기
함수 정의 화면에서 매개변수 "소리이름" 추가 →
함수 마지막 줄에 [소리] 소리이름 재생하기 추가 →
호출부: 효과주기 "배부름" 20 "냠냠!" "먹는소리"
03

레벨 계산 함수(판단형) 만들기 도전

친밀도 값을 매개변수로 받아서, 30 미만이면 "새싹", 30~70이면 "성장기", 70 초과면 "베스트프렌드"를 돌려주는 함수를 만들어보세요.

▸ 힌트 보기
함수 정의(값 반환): 친밀도등급 (친밀도값) →
만약 <친밀도값 > 70> 이라면 → 결과값을 "베스트프렌드"로 정하기
아니면 만약 <친밀도값 > 29> 이라면 → "성장기" / 아니면 → "새싹"
