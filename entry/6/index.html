블록을 글자로 옮겨 적기

지금까지 조립해온 블록들은 사실 모두 텍스트 코드로 바꿔 쓸 수 있어요. 엔트리 상단의 코드변환 버튼을 누르면 내가 만든 블록이 실시간으로 파이썬 코드로 바뀌는 걸 볼 수 있습니다. 이번 시간엔 그 텍스트 코드를 읽고 쓰는 법을 익혀봐요.

#코드변환 버튼 #들여쓰기 #if / for #변수·리스트·함수 문법 
# 친밀도가 70을 넘으면 칭찬하기
if 친밀도 > 70:
    말하기("베스트프렌드!")
else:
    말하기("조금 더 친해지자")
00 / OVERVIEW

블록 코딩과 텍스트 코딩, 뭐가 다를까?

블록 코딩은 정해진 퍼즐 조각을 끼워 맞추는 방식이라 오타가 날 수 없어요. 텍스트 코딩은 모든 문법을 직접 타이핑하기 때문에 대소문자 하나, 콜론(:) 하나, 들여쓰기 한 칸만 틀려도 프로그램 전체가 실행되지 않아요. 대신 텍스트 코딩은 실제 현업 개발자들이 쓰는 방식이라, 더 복잡하고 정교한 프로그램을 만들 수 있는 힘을 줍니다.

01

코드변환 버튼 활용하기

내가 만든 블록이 파이썬으로 어떻게 바뀌는지 직접 눈으로 확인합니다.

02

파이썬 기본 문법 읽기

변수 대입, 조건문, 반복문, 리스트, 함수의 텍스트 문법을 블록과 짝지어 이해합니다.

03

들여쓰기 규칙 몸에 익히기

블록이 "안쪽에 끼워진 것"이 파이썬에서는 "들여쓰기"로 표현된다는 걸 체험합니다.

⚠️

이 강의자료의 파이썬 예시 코드는 일반적인 파이썬 문법 구조(조건문·반복문·변수·리스트·함수)를 보여주기 위한 것이에요. 말하기·신호보내기 같은 엔트리 전용 명령어의 정확한 표기는 여러분이 만든 블록을 엔트리의 코드변환 버튼으로 직접 확인하는 것이 가장 정확합니다. 엔트리 프로그램이 자동으로 정확한 코드를 만들어주니, 그걸 읽고 이해하는 연습을 해보세요.

01 / HOW-TO

코드변환 버튼 사용법

실습은 "블록으로 먼저 만들고 → 변환해서 읽어보기" 순서로 진행하는 게 가장 효과적이에요.

STEP 1

지금까지 만든 펫 키우기 블록 코드를 그대로 엔트리에 열어둡니다.

STEP 2

엔트리 상단 메뉴바의 "코드변환" 아이콘을 클릭해 파이썬 보기로 전환합니다.

STEP 3

내가 알던 블록 하나하나가 어떤 줄의 텍스트 코드로 바뀌었는지 짝지어 읽어봅니다.

🌉

엔트리-파이썬은 블록 코딩과 진짜 파이썬 사이의 다리 역할을 해요. 처음엔 변환된 코드를 읽기만 하다가, 점점 직접 타이핑해서 같은 동작을 만들어보는 순서로 나아가면 됩니다.

02 / MAPPING

블록 ↔ 파이썬 문법 대응표

지금까지 배운 개념 5가지를 블록과 파이썬 코드로 나란히 비교해봅니다.

🔢

1. 변수 정하기 · 더하기

블록 코딩
골드를 100으로 정하기
골드에 -10만큼 더하기
텍스트 코딩 (파이썬)
골드 = 100 골드 += -10 # 골드 -= 10 과 같음
🔀

2. 만약 ~ 이라면 (조건문)

블록 코딩
만약 < 골드 > 9 > 이라면
[참]
골드에 -10만큼 더하기
[거짓]
"골드가 부족해요!" 말하기
텍스트 코딩 (파이썬)
if 골드 > 9: 골드 -= 10 else: 말하기("골드가 부족해요!")
🔁

3. 반복하기

블록 코딩
20 번 반복하기
1초 기다리기
남은 시간에 -1만큼 더하기
텍스트 코딩 (파이썬)
for i in range(20): 기다리기(1) 남은시간 -= 1
🎒

4. 리스트

블록 코딩
인벤토리에 "장난감공" 항목 추가하기
인벤토리의 1번째 항목
텍스트 코딩 (파이썬)
인벤토리.append("장난감공") 인벤토리[0] # 파이썬은 0번부터 셈!
🧩

5. 함수(나만의 블록)

블록 코딩
함수 정의: 효과주기 종류 수치
만약 < 종류 = "배부름" > 이라면
배부름에 수치만큼 더하기
텍스트 코딩 (파이썬)
def 효과주기(종류, 수치): if 종류 == "배부름": global 배부름 배부름 += 수치
📏

들여쓰기(Indentation)가 파이썬의 핵심 규칙이에요. 블록에서 "이 블록 안에 끼워진 것"은 파이썬에서 스페이스 4칸(또는 탭 1번) 더 들여써서 표현합니다. 들여쓰기 칸 수가 안 맞으면 어디까지가 조건문 안쪽 코드인지 파이썬이 알 수 없어서 에러가 나요.

04 / MISSIONS

읽는 것에 익숙해졌다면, 이제 직접 손으로 타이핑해보는 연습을 해보세요.

01

내 블록을 변환해서 따라 타이핑하기 쉬움

지난 시간에 만든 "먹이주기 신호를 받았을 때" 블록을 코드변환으로 확인한 뒤, 빈 파이썬 에디터에 똑같이 타이핑해보세요.

▸ 힌트 보기
한 글자씩 정확히 옮기는 것이 핵심이에요. 콜론(:)과 들여쓰기 칸 수를 특히 주의 깊게 확인하세요.
02

일부러 에러 내보고 고치기 보통

정상 작동하는 코드에서 들여쓰기를 한 칸 지워보거나 콜론을 빼보세요. 어떤 에러 메시지가 뜨는지 관찰하고, 원래대로 되돌려 고쳐보세요.

▸ 힌트 보기
파이썬은 에러 위치(줄 번호)를 알려줘요. 에러 메시지의 줄 번호부터 확인하는 습관을 들이면 디버깅이 훨씬 빨라집니다.
03

▸ 힌트 보기
