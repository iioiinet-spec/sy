영어 단어를 한국어 단어로 바꾸는 사전이 있습니다. 문장에서 등록된 단어만 번역하고 없는 단어는 그대로 출력하세요.

입력: N(1~100), 다음 N줄에 `영단어 번역어`, Q(1~100), 다음 Q줄에 공백으로 구분된 영단어 문장이 주어집니다. 문장은 한 줄에 1~20단어이며 마침표는 없습니다.

출력: 각 문장을 번역해 원래 공백 위치에 한 칸씩 띄워 출력합니다.

예제 입력

3
apple 사과
is 은
red 빨강
2
apple is red
banana is yellow

예제 출력

사과 은 빨강
banana 은 yellow

24. 간식 가게 재고 관리

도전 · P02·P03·P06

가게 재고를 관리합니다. ADD 상품 수량은 재고를 더하고, SELL 상품 수량은 재고가 충분하면 빼며 부족하면 FAIL을 출력합니다. COUNT 상품은 현재 재고를 출력합니다. 없는 상품의 재고는 0입니다.

입력: 첫 줄 M(1~1000), 다음 M줄에 `ADD 상품 양`, `SELL 상품 양`, `COUNT 상품` 명령이 주어집니다. 양은 1~1000입니다. 처음 재고는 모두 0입니다.

출력: SELL에 실패할 때 FAIL을 출력하고, COUNT 명령일 때 재고를 출력합니다. 다른 경우는 출력하지 않습니다.

예제 입력

9
ADD apple 5
COUNT apple
SELL apple 3
COUNT apple
SELL apple 4
COUNT apple
COUNT banana
ADD banana 2
COUNT banana

예제 출력

5
2
FAIL
2
0
2
