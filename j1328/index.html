정올 1328 빌딩

오른쪽에 있는 더 높은 빌딩 중 가장 가까운 빌딩을 찾는 문제입니다. 핵심 알고리즘은 오큰수 + 모노톤 스택입니다.

스택 모노톤 스택 오큰수 O(N) C언어

1. 문제 이해

N개의 빌딩이 왼쪽부터 1번, 2번, 3번, ..., N번까지 있습니다.

i번 빌딩에서 j번 빌딩을 볼 수 있으려면 다음 조건을 만족해야 합니다.

1. j는 i보다 오른쪽에 있어야 합니다. 즉, i < j
2. j번 빌딩이 i번 빌딩보다 높아야 합니다. 즉, H[i] < H[j]

각 빌딩마다 오른쪽에 있는 더 높은 빌딩 중 가장 가까운 번호를 출력합니다.

2. 예제 설명

예제 높이:

번호: 1 2 3 4 5 6
높이: 3 2 6 1 1 2
빌딩높이오른쪽에서 가장 가까운 더 높은 빌딩
1번33번
2번23번
3번6없음 → 0
4번16번
5번16번
6번2없음 → 0

3. 왜 스택을 써야 할까?

모든 빌딩마다 오른쪽을 끝까지 찾으면 너무 느립니다.

N이 100,000일 때 O(N²)은 시간 초과가 납니다.

이 문제는 각 빌딩이 스택에 한 번 들어가고, 한 번만 나오게 만들면 O(N)에 풀 수 있습니다.

4. 핵심 아이디어

오른쪽에서 왼쪽으로 확인합니다.

현재 빌딩보다 작거나 같은 빌딩은 현재 빌딩이 볼 수 없습니다.

그래서 스택 맨 위에서부터 현재 빌딩보다 작거나 같은 빌딩을 제거합니다.

while (스택이 비어 있지 않고, 스택 맨 위 빌딩 높이 <= 현재 빌딩 높이) {
    pop;
}

제거가 끝난 뒤 스택 맨 위에 남아 있는 빌딩이 바로 정답입니다.

6. 직접 정답 계산기

높이를 입력하고 정답을 바로 확인할 수 있습니다.

7. 알고리즘 정리

1. 빌딩 높이를 배열 H에 저장합니다.

2. 오른쪽에서 왼쪽으로 i를 이동합니다.

3. 스택에는 빌딩 번호를 저장합니다.

4. 현재 빌딩보다 작거나 같은 빌딩은 pop합니다.

5. pop이 끝난 뒤 스택이 비어 있으면 정답은 0입니다.

6. 스택이 비어 있지 않으면 스택 맨 위 번호가 정답입니다.

7. 현재 빌딩 번호를 스택에 push합니다.

8. 정답 C 코드

#include <stdio.h>

#define MAXN 100005

int N;
int H[MAXN];
int answer[MAXN];

int stack[MAXN];
int top = -1;

int main() {
    scanf("%d", &N);

    for (int i = 1; i <= N; i++) {
        scanf("%d", &H[i]);
    }

    for (int i = N; i >= 1; i--) {
        while (top != -1 && H[stack[top]] <= H[i]) {
            top--;
        }

        if (top == -1) {
            answer[i] = 0;
        } else {
            answer[i] = stack[top];
        }

        stack[++top] = i;
    }

    for (int i = 1; i <= N; i++) {
        printf("%d\\n", answer[i]);
    }

    return 0;
}

9. 코드 자세한 설명

1. 배열 준비

int H[MAXN];
int answer[MAXN];
int stack[MAXN];

1. H[i]는 i번 빌딩의 높이입니다.

2. answer[i]는 i번 빌딩에서 보이는 가장 가까운 빌딩 번호입니다.

3. stack에는 후보 빌딩의 번호를 저장합니다.

2. 오른쪽부터 보기

for (int i = N; i >= 1; i--)

오른쪽에 있는 빌딩 중 가장 가까운 높은 빌딩을 찾아야 하므로 오른쪽부터 확인합니다.

3. 필요 없는 빌딩 제거

while (top != -1 && H[stack[top]] <= H[i]) {
    top--;
}

현재 빌딩보다 낮거나 같은 빌딩은 현재 빌딩이 볼 수 없습니다.

그래서 스택에서 제거합니다.

4. 정답 저장

if (top == -1) {
    answer[i] = 0;
} else {
    answer[i] = stack[top];
}

스택이 비어 있으면 오른쪽에 더 높은 빌딩이 없습니다.

스택이 비어 있지 않으면 맨 위 빌딩이 가장 가까운 더 높은 빌딩입니다.

5. 현재 빌딩 push

stack[++top] = i;

현재 빌딩도 왼쪽에 있는 빌딩들에게는 후보가 될 수 있으므로 스택에 넣습니다.
