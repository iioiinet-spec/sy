자연수 N 의 약수가 정확히 15개입니다. 이러한 N 중에서 가장 작은 수를 구하시오.

생각의 실마리 — N = pa qb … 로 소인수분해했을 때 약수의 개수는 (a+1)(b+1)… 입니다. 15를 두 수의 곱으로 쪼개는 방법은 몇 가지인가요? 그리고 큰 지수를 작은 소수에 주어야 할까요, 큰 소수에 주어야 할까요?
A2거듭제곱의 나머지정수 · 합동

32024 을 7로 나눈 나머지를 구하시오.

생각의 실마리 — 31, 32, 33, … 을 7로 나눈 나머지를 차례로 적어 보세요. 어느 순간 같은 값이 다시 나타납니다. 그 주기를 찾으면 2024를 직접 계산할 필요가 없습니다.

A4최대공약수와 최소공배수정수 · GCD·LCM

두 자연수 a, b 에 대하여 최대공약수가 12, 최소공배수가 720 입니다. 이러한 순서쌍 (a, b) 중 a < b 인 것은 모두 몇 개인지 구하시오.

생각의 실마리 — a = 12m, b = 12n 으로 놓으면 m과 n은 서로소입니다. 그리고 (최대공약수) × (최소공배수) = ab 이므로 mn 의 값이 정해집니다. 그 값을 서로소인 두 수의 곱으로 쪼개면 됩니다.
A5부정방정식의 자연수해정수 · 부정방정식

3x + 5y = 100 을 만족하는 자연수 순서쌍 (x, y) 에 대하여, xy 의 최댓값을 구하시오.

생각의 실마리 — 3x = 100 − 5y 에서 우변이 3의 배수여야 합니다. 이 조건으로 y의 후보가 크게 줄어듭니다. 또 합이 일정한 두 수의 곱은 두 수가 가까울수록 큽니다.
A6대칭식의 값대수 · 곱셈 공식

x + 1/x = 3 일 때, x3 + 1/x3 의 값을 구하시오.

생각의 실마리 — x를 직접 구하려 하면 무리수가 나와 복잡합니다. (x + 1/x)3 을 전개해 보세요. x3 + 1/x3 말고 무엇이 더 나오나요? 그것이 다시 x + 1/x 로 표현된다는 점이 열쇠입니다.
A7조건이 붙은 식의 값대수 · 인수분해

a + b + c = 0 이고 abc ≠ 0 일 때, (a3 + b3 + c3) ÷ (abc) 의 값을 구하시오.

생각의 실마리 — a3+b3+c3 − 3abc 는 유명한 인수분해 공식이 있습니다. 그 인수 중 하나가 a+b+c 라는 점을 이용하세요. 값을 대입해 확인도 꼭 해 보세요.

A8직각삼각형의 내접원기하 · 피타고라스

세 변의 길이가 각각 9, 12, 15 인 직각삼각형에 내접하는 원의 반지름을 구하시오.

생각의 실마리 — 두 가지 길이 있습니다. ① 삼각형의 넓이를 두 가지 방법으로 나타내기 — (넓이) = r × (둘레의 절반). ② 직각삼각형에서는 r = (a + b − c) / 2 (c는 빗변). 두 방법의 답이 같은지 확인해 보세요.
A9삼각형 넓이의 비기하 · 넓이비

삼각형 ABC의 넓이가 90 입니다. 변 BC 위의 점 D는 BD : DC = 1 : 2, 변 AB 위의 점 E는 AE : EB = 2 : 1 을 만족합니다. 삼각형 ADE의 넓이를 구하시오.

생각의 실마리 — 높이가 같은 두 삼각형의 넓이비 = 밑변의 비. 이 사실을 두 번 씁니다. △ADE를 △ABC와 바로 비교하려 하면 막힙니다. 중간 다리가 될 삼각형을 하나 놓아 보세요.
A10반드시 존재하는 두 수조합 · 비둘기집

1부터 100까지의 자연수 중에서 서로 다른 n 개를 뽑을 때, 뽑은 수 중에 한 수가 다른 수의 배수가 되는 두 수가 반드시 존재하도록 하는 n 의 최솟값을 구하시오.

생각의 실마리 — 모든 자연수는 (홀수) × 2k 꼴로 단 하나로 쓸 수 있습니다. 1~100의 홀수는 몇 개인가요? 그 홀수를 서랍이라 생각하면 무엇이 보이나요? 그리고 반례(그만큼 뽑아도 배수 쌍이 없는 경우)도 하나 찾아보세요.

연습 포인트 — 일의 자리는 10으로 나눈 나머지와 같습니다. 주기를 찾아 2025를 그 주기로 나눈 나머지를 보세요. 나머지가 0일 때 주기의 몇 번째를 골라야 하는지 특히 주의해야 합니다.

B5부정방정식의 자연수해정수 · 부정방정식

7x + 4y = 100 을 만족하는 자연수 순서쌍 (x, y) 는 모두 몇 개인지 구하시오. 또 그중 x + y 가 최소인 값을 구하시오.

연습 포인트 — 4y = 100 − 7x 에서 우변이 4의 배수가 되려면 7x 가 4로 나누어떨어져야 합니다. 7과 4는 서로소이므로 x 자체가 4의 배수여야 하지요.
B6대칭식의 값대수 · 곱셈 공식

연습 포인트 — A6은 합이었지만 이번엔 차입니다. (x − 1/x)2 을 전개하면 가운데 항의 부호가 A6과 어떻게 달라지는지 확인하세요.
B7조건이 붙은 식의 값대수 · 곱셈 공식
