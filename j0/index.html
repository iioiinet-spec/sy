Monotonic Stack

오른쪽에서 처음 만나는 더 큰 수를 단계별로 이해하는 인터랙티브 강의자료

1. Monotonic Stack이란?

Monotonic Stack은 스택 안의 값들이 항상 한 방향으로 정리되도록 유지하는 자료구조입니다. 한국어로는 단조 스택이라고 합니다.

증가 스택: 작은 값 → 큰 값 감소 스택: 큰 값 → 작은 값

주로 다음 문제에서 사용합니다.

1. 오른쪽에서 처음 만나는 더 큰 수
2. 왼쪽에서 처음 만나는 더 큰 수
3. 오른쪽에서 처음 만나는 더 작은 수
4. 탑 문제
5. 막대그래프 최대 직사각형

2. 예제 문제

N개의 수가 주어질 때, 각 수에 대해 오른쪽에 있으면서 자신보다 큰 수 중 가장 가까운 수를 출력합니다. 없으면 -1을 출력합니다.

3. 핵심 아이디어

왼쪽에서 오른쪽으로 보면서, 아직 답을 찾지 못한 인덱스를 스택에 넣습니다.

현재 값 A[i]가 스택 top의 값보다 크다면? 현재 값 A[i]는 stack[top] 위치의 정답이다. answer[stack[top]] = A[i] pop 한다.

스택에 남아 있는 인덱스들은 아직 오른쪽에서 더 큰 값을 찾지 못한 값들입니다.

5. 코드 작성 순서

1단계. 배열 선언

#define MAXN 200000

int A[MAXN];
int answer[MAXN];
int stack[MAXN];

A는 입력 배열, answer는 정답 배열, stack은 아직 답을 못 찾은 인덱스를 저장합니다.

2단계. 입력 받기

scanf("%d", &N);

for (int i = 0; i < N; i++) {
    scanf("%d", &A[i]);
}

3단계. 정답 배열을 -1로 초기화

for (int i = 0; i < N; i++) {
    answer[i] = -1;
}

4단계. 배열로 스택 만들기

int top = -1;

stack[++top] = i;  // push
top--;             // pop
stack[top];        // top 확인

5단계. 핵심 while문 작성

while (top != -1 && A[stack[top]] < A[i]) {
    answer[stack[top]] = A[i];
    top--;
}

6단계. 현재 인덱스를 스택에 넣기

stack[++top] = i;

6. 완성 C 코드

#include <stdio.h>

#define MAXN 200000

int A[MAXN];
int answer[MAXN];
int stack[MAXN];

int main() {
    int N;

    scanf("%d", &N);

    for (int i = 0; i < N; i++) {
        scanf("%d", &A[i]);
    }

    for (int i = 0; i < N; i++) {
        answer[i] = -1;
    }

    int top = -1;

    for (int i = 0; i < N; i++) {
        while (top != -1 && A[stack[top]] < A[i]) {
            answer[stack[top]] = A[i];
            top--;
        }

        stack[++top] = i;
    }

    for (int i = 0; i < N; i++) {
        printf("%d ", answer[i]);
    }

    return 0;
}

7. 시간복잡도

각 인덱스는 스택에 한 번 들어가고, 한 번 나옵니다.

push 최대 N번 pop 최대 N번 전체 시간복잡도 = O(N)

8. 핵심 정리

1. 스택에는 아직 답을 못 찾은 인덱스를 넣는다. 2. 현재 값이 스택 top의 값보다 크면 정답을 찾은 것이다. 3. pop하면서 answer를 채운다. 4. 현재 인덱스를 push한다. 5. 끝까지 남은 인덱스의 답은 -1이다.
