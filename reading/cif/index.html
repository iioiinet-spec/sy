오늘의 목표

조건을 읽고, 어느 문장이 실행될지 말할 수 있어요.

공부하는 순서

1. 이야기 → 2. 코드 한 줄씩 읽기 → 3. 출력 예상하기 → 4. 값 바꾸기

1~6장부터 시작하고, 7~10장은 천천히 도전해요. 모든 예제는 완전한 C 프로그램입니다.

1. 조건문은 무엇일까요?

우리 생활의 “만약 ~라면”을 컴퓨터 말로 표현해요.

아침에 창밖을 보세요. 비가 오면 우산을 챙기고, 비가 오지 않으면 우산을 놓고 나갑니다.

이렇게 상황을 살펴보고 행동을 정하는 문장을 조건문이라고 해요. C언어에서도 조건문으로 서로 다른 일을 선택할 수 있어요.

우산비가 온다면 → 우산 챙기기
신호등빨간불이라면 → 멈추기
간식사과가 3개 이상이라면 → 친구와 나누기
기억해요. 조건을 먼저 확인하고, 맞는 길을 선택해요.

2. C언어 코드의 약속을 알아봐요

if 코드를 읽기 위한 기본 틀과 기호를 먼저 만나요.

if는 “만약 ~라면”이라는 뜻이에요. printf()는 화면에 글자를 보여 줘요. int는 숫자를 저장할 때 사용해요.

C언어는 코드 맨 위에 #include <stdio.h>를 적고, int main(void) {에서 시작해 return 0;과 }로 끝내요. 초보자는 이 부분을 프로그램의 준비 틀이라고 생각해도 돼요.

=는 값을 저장하고, ==는 같은지 물어봐요. 조건은 소괄호 ( ), 실행할 코드는 중괄호 { }로 묶어요. 명령문 끝에는 보통 세미콜론 ;을 붙여요.

코드 또는 기호읽는 방법
int main(void) {프로그램이 시작되는 기본 틀
int숫자를 담는 이름표 만들기
char글자 한 개를 담는 이름표 만들기
if (조건)만약 조건이 맞으면
printf("안녕\n");안녕이라고 보여 주고 줄 바꾸기
= / ==저장하기 / 같은지 비교하기
{ }안쪽 문장을 묶기
;명령문의 끝 표시
return 0;프로그램을 정상적으로 마치기
꼭 기억해요! C언어는 if (조건) { ... }처럼 쓰고, 글자 한 개는 'R', 화면에 보여 줄 글은 "멈춰요"처럼 따옴표 모양이 달라요.

기호가 보이는 첫 번째 코드

한 줄씩 소리 내어 읽어 봐요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int rain = 1;
    if (rain == 1) {
        printf("우산 챙기기\n");
    }
    printf("학교 가기\n");
    return 0;
}
실행 결과
우산 챙기기
학교 가기
한 줄씩 읽어 봐요
  1. int rain = 1;은 rain이라는 숫자 이름표에 1을 넣어요. 1은 “비가 옴”이라는 약속이에요.
  2. if (rain == 1)은 “rain이 1과 같은가요?”라고 물어요.
  3. 참이므로 중괄호 안의 “우산 챙기기”를 보여 줘요.
  4. 중괄호 바깥의 “학교 가기”도 출력해요.

바꿔 보기 rain = 0;으로 바꾸면 “학교 가기”만 출력돼요.

3. if: 맞으면 실행해요

조건이 참(1)일 때만 { } 안의 일을 실행해요.

C언어의 조건식에서는 0은 거짓, 0이 아닌 값은 참으로 판단해요. 처음에는 1을 “맞아요”, 0을 “아니에요”로 생각해 보세요.

예제 1. 우산 챙기기

비가 오는 날의 약속이에요. 1 = 비, 0 = 맑음.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int rain = 1;
    if (rain == 1) {
        printf("우산을 챙겨요\n");
    }
    printf("출발!\n");
    return 0;
}
실행 결과
우산을 챙겨요
출발!
한 줄씩 읽어 봐요
  1. rain에는 1이 저장되어 있어요.
  2. 1 == 1은 참이에요.
  3. 중괄호 안의 “우산을 챙겨요”가 출력돼요.
  4. 바깥에 있는 “출발!”도 출력돼요.

바꿔 보기 비가 오지 않는 rain = 0;으로 고쳐 보세요.

예제 2. 사과 나누기

사과가 3개 이상이면 친구와 나눌 거예요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int apple = 4;
    if (apple >= 3) {
        printf("친구와 나눠 먹자\n");
    }
    printf("맛있게 먹자\n");
    return 0;
}
실행 결과
친구와 나눠 먹자
맛있게 먹자
한 줄씩 읽어 봐요
  1. apple은 4개예요.
  2. 4 >= 3은 “4가 3보다 크거나 같은가요?”예요. 참이에요.
  3. 두 문장이 차례로 출력돼요.

바꿔 보기 apple = 2;라면 첫 번째 문장은 건너뛰어요.

4. if-else: 둘 중 하나를 골라요

맞으면 if, 틀리면 else로 가요.

else는 “그렇지 않다면”이라는 뜻이에요. if와 else의 중괄호 중 딱 하나만 실행해요.

예제 3. 신호등 살펴보기

R은 빨간불(Red), G는 초록불(Green)의 첫 글자예요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    char light = 'R';
    if (light == 'R') {
        printf("멈춰요\n");
    } else {
        printf("주위를 살펴요\n");
    }
    return 0;
}
실행 결과
멈춰요
한 줄씩 읽어 봐요
  1. char는 글자 한 개를 저장하는 자료형이에요. 'R'은 빨간불이에요.
  2. light == 'R'이 참이에요.
  3. if 쪽의 “멈춰요”가 나오고 else 쪽은 실행하지 않아요.

바꿔 보기 light = 'G';로 바꾸면 “주위를 살펴요”가 나와요. 초록불에도 주변을 확인해요.

예제 4. 숙제 먼저, 게임 나중

1은 숙제를 했음, 0은 아직 안 했다는 뜻이에요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int homework = 0;
    if (homework == 1) {
        printf("게임 시간!\n");
    } else {
        printf("숙제를 먼저 해요\n");
    }
    return 0;
}
실행 결과
숙제를 먼저 해요
한 줄씩 읽어 봐요
  1. homework에는 0이 들어 있어요.
  2. 0 == 1은 거짓이에요.
  3. else 쪽의 “숙제를 먼저 해요”가 나와요.

바꿔 보기 homework = 1;로 바꾸어 보세요.

직접 체험: 신호등 색을 바꿔 보세요

멈춰요

light == 'R'이 참이므로 if를 실행해요.

이 체험은 C 코드의 조건 판단을 화면에 보여 주는 활동이에요.

5. 비교 기호는 숫자 질문이에요

같다·다르다·크다·작다를 읽을 수 있어요.

숫자를 비교하는 기호를 질문처럼 읽어 보세요. 파이썬과 비교 기호는 거의 같아요.

기호뜻예결과
=값을 저장해요int a = 3;a에 3 저장
==같나요?3 == 3참
!=다른가요?3 != 4참
>더 큰가요?5 > 2참
<더 작은가요?2 < 5참
>=크거나 같나요?5 >= 5참
<=작거나 같나요?3 <= 2거짓
주의! 저장하는 =와 비교하는 ==는 서로 달라요.

예제 5. 키가 기준에 도착했나요?

연습용으로 키 기준을 120이라고 정했어요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int height = 120;
    if (height >= 120) {
        printf("키 조건 통과!\n");
    } else {
        printf("다음에 도전해요\n");
    }
    return 0;
}
실행 결과
키 조건 통과!
한 줄씩 읽어 봐요
  1. 키는 120이에요.
  2. 120 >= 120은 참이에요. “크거나 같다”는 같을 때도 참이에요.
  3. “키 조건 통과!”가 출력돼요.

바꿔 보기 키를 119로 바꿔 보세요. 실제 탑승 여부는 시설의 모든 안전 규정을 따라야 해요.

6. else if: 선택이 세 개라면?

위에서부터 살펴보고 처음 참인 길 하나를 골라요.

C언어에는 파이썬의 elif 대신 else if가 있어요. 처음 조건이 거짓이면 다음 조건을 물어요.

예제 6. 동전으로 간식 고르기

동전 5개 이상은 초콜릿, 3개 이상은 젤리, 나머지는 물이에요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int coin = 4;
    if (coin >= 5) {
        printf("초콜릿\n");
    } else if (coin >= 3) {
        printf("젤리\n");
    } else {
        printf("물\n");
    }
    return 0;
}
실행 결과
젤리
한 줄씩 읽어 봐요
  1. 4 >= 5는 거짓이어서 첫 번째 길을 건너뛰어요.
  2. 4 >= 3은 참이에요. “젤리”를 보여 줘요.
  3. 첫 번째로 맞는 길을 찾았으니 그 뒤는 확인하지 않아요.

바꿔 보기 동전을 2개, 5개, 8개로 바꿔 결과를 미리 말해 보세요.

예제 7. 기분 온도계

1은 신남, 2는 차분함, 3은 쉬고 싶음이에요.

실행 결과
차분해요
한 줄씩 읽어 봐요
  1. mood는 2예요.
  2. 2 == 1은 거짓이에요.
  3. 2 == 2는 참이므로 “차분해요”만 출력해요.

바꿔 보기 기분을 1 또는 3으로 바꿔 보세요.

직접 체험: 동전 개수를 움직여 보세요

젤리

7. && · || · ! : 질문을 이어 붙여요

두 조건을 동시에 보거나, 하나라도 보거나, 참·거짓을 뒤집어요.

C언어는 파이썬의 and, or, not 대신 기호를 사용해요. &&는 둘 다, ||는 하나라도, !는 반대예요.

예제 8. 둘 다 있어야 입장: &&

입장권도 있고 줄도 섰다면 입장해요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int ticket = 1;
    int waited = 1;
    if (ticket && waited) {
        printf("입장할 수 있어요\n");
    } else {
        printf("아직 준비 중이에요\n");
    }
    return 0;
}
실행 결과
입장할 수 있어요
한 줄씩 읽어 봐요
  1. ticket과 waited가 모두 1이에요.
  2. &&는 두 가지가 모두 참일 때만 참이에요.

바꿔 보기 waited = 0;으로 바꾸면 어떻게 될까요?

예제 9. 둘 중 하나면 주말: ||

S는 토요일(Saturday), U는 일요일(Sunday)을 나타내는 약속이에요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    char day = 'U';
    if (day == 'S' || day == 'U') {
        printf("주말이에요\n");
    } else {
        printf("평일이에요\n");
    }
    return 0;
}
실행 결과
주말이에요
한 줄씩 읽어 봐요
  1. day는 'U'예요.
  2. 토요일은 아니지만 일요일과 같으므로 한쪽이 참이에요.
  3. ||는 하나만 참이어도 참이어서 “주말이에요”가 나와요.

바꿔 보기 day = 'W';로 바꿔 평일을 확인해 보세요.

예제 10. 비가 오지 않아요: !

느낌표 !는 참과 거짓을 바꿔 줘요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int rain = 0;
    if (!rain) {
        printf("산책을 생각해 봐요\n");
    }
    return 0;
}
실행 결과
산책을 생각해 봐요
한 줄씩 읽어 봐요
  1. rain은 0이므로 거짓이에요.
  2. !0은 참이에요.
  3. 그래서 산책 문장이 출력돼요.

바꿔 보기 rain = 1;로 바꾸면 아무것도 출력되지 않아요.

8. 내가 입력한 숫자로 판단해요

scanf로 숫자를 입력받아 if에서 비교해요.

scanf("%d", &coin);은 숫자 하나를 읽어서 coin에 저장해요. %d는 정수를 읽는 약속이고, &coin은 저장할 coin의 위치를 알려 줘요. 처음에는 한 덩어리로 외워도 좋아요.

예제 11. 내 동전 개수 입력하기

숫자를 입력해서 결과가 달라지는 프로그램이에요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int coin;
    printf("동전 몇 개?\n");
    scanf("%d", &coin);
    if (coin >= 5) {
        printf("간식 선택 가능\n");
    } else {
        printf("동전을 더 모아요\n");
    }
    return 0;
}
실행 결과 (입력: 6)
동전 몇 개?
간식 선택 가능
한 줄씩 읽어 봐요
  1. “동전 몇 개?”라는 질문을 보여 줘요.
  2. 숫자 6을 입력하면 coin에 6을 저장해요.
  3. 6 >= 5는 참이어서 “간식 선택 가능”이 출력돼요.

바꿔 보기 입력 2를 사용하면 “동전을 더 모아요”가 나와요. 숫자 이외의 입력은 아직 사용하지 않아요.

9. 조건 속에 또 조건: 중첩 if

큰 문을 통과한 뒤 작은 문을 확인해요.

중괄호 안에 또 다른 if가 들어갈 수 있어요. 바깥쪽 질문이 참일 때 안쪽 질문을 확인해요.

예제 12. 보물상자 열기

열쇠가 있어야 암호를 확인할 수 있어요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int key = 1;
    int password = 0;
    if (key) {
        if (password) {
            printf("보물상자 열기!\n");
        } else {
            printf("암호가 필요해요\n");
        }
    } else {
        printf("열쇠를 찾아요\n");
    }
    return 0;
}
실행 결과
암호가 필요해요
한 줄씩 읽어 봐요
  1. key가 1이므로 바깥 if 안으로 들어가요.
  2. password는 0이므로 안쪽 else로 가요.
  3. “암호가 필요해요”를 출력해요.

바꿔 보기 password = 1; 또는 key = 0;으로 바꿔 세 가지 결과를 관찰해요.

10. 한 걸음 더 배우기

파이썬과 닮았지만 C언어에서는 다르게 쓰는 표현을 알아봐요.

여기부터는 초등 저학년 학생이 선생님과 함께 읽어도 좋아요. 앞의 1~9장을 먼저 익힌 후 도전해 보세요.

예제 13. 사이에 있는 숫자: &&

예제 17. 순서가 바뀌면 결과도 달라져요

C언어에서도 큰 기준을 먼저 검사해야 해요.

C언어 코드 (복사해서 실행 가능)
#include <stdio.h>

int main(void) {
    int score = 95;
    if (score >= 60) {
        printf("보통\n");
    } else if (score >= 90) {
        printf("우수\n");
    }
    return 0;
}
실행 결과
보통
한 줄씩 읽어 봐요
  1. 95는 이미 60 이상이어서 첫 if가 참이에요.
  2. “보통”이 나오고 else if는 검사하지 않아요.
  3. 90 이상을 먼저 검사해야 “우수”가 나와요.

바꿔 보기 90 이상을 첫 번째 if로 옮겨 보세요.

실수하기 쉬운 다섯 가지

1. 비교 기호를 잘못 써요
틀린 부분
int x = 5;
if (x = 5) {
    printf("같아요\n");
}
바르게 고치기
int x = 5;
if (x == 5) {
    printf("같아요\n");
}

=는 값을 저장하므로 비교는 ==를 써요. C에서는 컴파일되지만 잘못된 결과가 나올 수 있어요.

2. 소괄호를 빼먹어요
틀린 부분
if apple >= 3 {
    printf("네\n");
}
바르게 고치기
if (apple >= 3) {
    printf("네\n");
}

C언어의 조건식은 ( )로 감싸야 해요.

3. 중괄호를 닫지 않아요
틀린 부분
if (x > 5) {
    printf("네\n");
바르게 고치기
if (x > 5) {
    printf("네\n");
}

{ 를 열었다면 } 로 닫아요.

4. 세미콜론을 잊어요
틀린 부분
printf("안녕\n")
바르게 고치기
printf("안녕\n");

printf 명령 끝에는 ;을 붙여요.

5. else if 순서가 달라요
틀린 부분
if (score >= 60) {
    printf("보통\n");
} else if (score >= 90) {
    printf("우수\n");
}
바르게 고치기
if (score >= 90) {
    printf("우수\n");
} else if (score >= 60) {
    printf("보통\n");
}

더 높은 기준부터 먼저 검사해요.

11. 오늘 배운 것 정리

□ if는 “만약 ~라면”이에요.

□ else는 “그렇지 않다면”이에요.

□ else if는 “앞 조건이 아니면 다음 조건 확인”이에요.

□ 조건은 ( ) 안에 쓰고, 실행할 코드는 { } 안에 써요.

□ ==는 비교이고, =는 값을 넣는 기호예요.

□ printf("글\n");은 글을 화면에 보여 줘요.

□ &&는 둘 다, ||는 하나라도, !는 반대예요.
