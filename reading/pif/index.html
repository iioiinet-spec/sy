오늘의 목표

조건문을 읽고, 어떤 결과가 나올지 말할 수 있어요.

공부하는 순서

① 이야기 읽기 → ② 코드 읽기 → ③ 결과 예상하기 → ④ 직접 고치기

학습 방법: 1~6장부터 읽은 뒤 쉬는 시간을 갖고, 7~10장은 천천히 도전해요.

1. 조건문은 무엇일까요?

우리 생활의 “만약 ~라면”을 컴퓨터 말로 표현해요.

아침에 창밖을 보세요. 비가 오면 우산을 챙기고, 비가 오지 않으면 우산을 놓고 나갑니다.

이처럼 상황을 살펴보고 행동을 정하는 문장을 조건문이라고 해요. 컴퓨터도 조건문으로 서로 다른 일을 할 수 있어요.

우산비가 온다면 → 우산 챙기기
신호등빨간불이라면 → 멈추기
간식사과가 3개 이상이라면 → 친구에게 나누기
기억해요. 조건을 먼저 확인하고, 조건에 맞는 행동을 해요.

2. 파이썬 코드의 약속 네 가지

if 코드를 읽기 위한 기호를 먼저 만나요.

if는 영어로 “만약 ~라면”이라는 뜻이에요. print()는 화면에 글자를 보여 주는 명령이에요.

=는 값을 넣는 기호, ==는 두 값이 같은지 묻는 기호예요. :를 쓴 다음에는 명령을 오른쪽으로 공백 4칸 들여써요.

기호어떻게 읽을까요?
if만약 ~라면
print()화면에 보여 줘
=값 저장하기
==같은지 물어보기
:여기부터 안쪽 일이 시작돼요
공백 4칸if 안쪽의 일이에요

기호가 보이는 첫 번째 코드

하나씩 소리 내어 읽어 봐요.

파이썬 코드
weather = "비"
if weather == "비":
    print("우산 챙기기")
print("학교 가기")
실행 결과
우산 챙기기
학교 가기
한 줄씩 읽어 봐요
  1. weather라는 이름표에 “비”를 넣어요. (`=`: 저장)
  2. “weather가 비와 같나요?”라고 물어요. (`==`: 비교)
  3. 맞으므로 4칸 들어간 줄의 “우산 챙기기”를 보여 줘요.
  4. 들여쓰지 않은 “학교 가기”는 언제나 보여 줘요.

바꿔 보기 ==를 =로 바꾸면 비교할 수 없어요. 그대로 두세요.

3. if: 맞으면 실행해요

조건이 참(True)일 때만 들여쓴 줄이 실행돼요.

조건이 맞으면 참(True), 맞지 않으면 거짓(False)이라고 해요. if는 참일 때만 안쪽 일을 해요.

예제 1. 우산 챙기기

오늘 날씨가 비인 경우예요.

파이썬 코드
weather = "비"
if weather == "비":
    print("우산을 챙겨요")
print("출발!")
실행 결과
우산을 챙겨요
출발!
한 줄씩 읽어 봐요
  1. weather는 “비”예요.
  2. “비” == “비”는 참이에요.
  3. “우산을 챙겨요”를 출력해요.
  4. “출발!”은 if 밖에 있으므로 꼭 출력해요.

바꿔 보기 날씨를 "맑음"으로 바꾸면 “출발!”만 나와요.

예제 2. 사과 나누기

사과가 3개 이상이면 친구와 나눌 거예요.

파이썬 코드
apple = 4
if apple >= 3:
    print("친구와 나눠 먹자")
print("맛있게 먹자")
실행 결과
친구와 나눠 먹자
맛있게 먹자
한 줄씩 읽어 봐요
  1. 사과는 4개예요.
  2. 4 >= 3 은 “4는 3 이상인가?”예요. 참이에요.
  3. 두 줄 모두 화면에 나와요.

바꿔 보기 사과가 2개라면 첫 번째 출력문은 건너뛰어요.

4. if-else: 둘 중 하나를 골라요

맞으면 if, 틀리면 else로 가요.

else는 “그렇지 않다면”이라는 뜻이에요. if와 else의 안쪽 길 중 하나만 선택해요.

예제 3. 신호등 살펴보기

빨간불인지 먼저 확인해요.

파이썬 코드
light = "빨강"
if light == "빨강":
    print("멈춰요")
else:
    print("주위를 살펴요")
실행 결과
멈춰요
한 줄씩 읽어 봐요
  1. 빨간불과 같은지 물어요.
  2. 같으므로 if 쪽의 “멈춰요”를 보여 줘요.
  3. else 쪽은 실행하지 않아요.

바꿔 보기 light = "초록"으로 바꾸면 “주위를 살펴요”가 나와요. 초록불이어도 주변을 확인해요.

예제 4. 숙제 먼저, 게임 나중

숙제를 했는지에 따라 알림을 다르게 보여 줘요.

파이썬 코드
homework = False
if homework == True:
    print("게임 시간!")
else:
    print("숙제를 먼저 해요")
실행 결과
숙제를 먼저 해요
한 줄씩 읽어 봐요
  1. homework에는 거짓(False)이 들어 있어요.
  2. False == True 는 거짓이에요.
  3. else의 “숙제를 먼저 해요”가 나와요.

바꿔 보기 False를 True로 바꿔 실행해 보세요.

직접 체험: 신호등 바꿔 보기

멈춰요

빨강이므로 if 쪽이 실행돼요.

5. 비교 기호는 숫자 질문이에요

같다·다르다·크다·작다를 읽을 수 있어요.

기호를 무조건 외우지 말고, 숫자 질문으로 읽어 보세요.

기호뜻예결과
=값을 넣어요a = 3a에 3 저장
==같나요?3 == 3참
!=다른가요?3 != 4참
>더 큰가요?5 > 2참
<더 작은가요?2 < 5참
>=크거나 같나요?5 >= 5참
<=작거나 같나요?3 <= 2거짓
주의! 저장하는 = 한 개와 비교하는 == 두 개는 서로 달라요.

예제 5. 내 키와 롤러코스터 기준

숫자 비교를 간단히 연습해요.

파이썬 코드
height = 120
if height >= 120:
    print("키 조건을 통과했어요")
else:
    print("다음에 도전해요")
실행 결과
키 조건을 통과했어요
한 줄씩 읽어 봐요
  1. 키는 120이라고 저장해요.
  2. 120 >= 120 은 참이에요. “크거나 같다”니까 같은 것도 포함돼요.
  3. 첫 번째 문장이 나와요.

바꿔 보기 키를 119로 바꾸면 else가 실행돼요. 실제 탑승은 시설의 모든 안전 규정을 따라야 해요.

6. elif: 선택이 세 개라면?

if부터 차례로 확인하고 처음 참인 길 하나를 골라요.

elif는 “앞의 조건은 아니고, 이 조건이라면?”이라는 뜻이에요. 먼저 큰 기준부터 차례로 적어요.

예제 6. 동전으로 간식 고르기

동전이 5개 이상이면 초콜릿, 3개 이상이면 젤리, 그보다 적으면 물을 골라요.

파이썬 코드
coin = 4
if coin >= 5:
    print("초콜릿")
elif coin >= 3:
    print("젤리")
else:
    print("물")
실행 결과
젤리
한 줄씩 읽어 봐요
  1. 4 >= 5 는 거짓이에요. 첫 번째 길을 지나가요.
  2. 4 >= 3 은 참이에요. “젤리”를 보여 줘요.
  3. 한 번 선택했으니 else는 보지 않아요.

바꿔 보기 동전을 2개, 5개, 8개로 바꾸며 어떤 결과가 나오는지 예상해 보세요.

예제 7. 기분 온도계

숫자로 고른 기분에 맞춰 인사를 출력해요.

파이썬 코드
mood = 2
if mood == 1:
    print("신나요")
elif mood == 2:
    print("차분해요")
else:
    print("쉬고 싶어요")
실행 결과
차분해요
한 줄씩 읽어 봐요
  1. mood는 2예요.
  2. 2 == 1은 거짓이에요.
  3. 2 == 2는 참이므로 “차분해요”만 나와요.

바꿔 보기 기분을 1 또는 3으로 바꿔 보세요.

직접 체험: 동전 개수를 움직여 보세요

젤리

5개 미만, 3개 이상이므로 젤리예요.

인쇄할 때에는 2개 → 물 / 4개 → 젤리 / 5개 → 초콜릿으로 기억해요.

7. and · or · not: 질문을 이어 붙여요

두 조건을 동시에 보거나, 둘 중 하나를 보거나, 결과를 뒤집어요.

and는 둘 다, or는 하나라도, not은 반대라는 뜻이에요.

예제 8. 둘 다 있어야 입장: and

입장권도 있고, 줄도 섰다면 입장할 수 있어요.

파이썬 코드
ticket = True
waited = True
if ticket and waited:
    print("입장할 수 있어요")
else:
    print("아직 준비 중이에요")
실행 결과
입장할 수 있어요
한 줄씩 읽어 봐요
  1. ticket과 waited가 모두 True인지 봐요.
  2. 둘 다 맞으므로 첫 번째 문장이 나와요.

바꿔 보기 waited = False로 바꾸면 어떻게 될까요?

예제 9. 둘 중 하나면 좋아: or

토요일 또는 일요일이면 주말이에요.

파이썬 코드
day = "일"
if day == "토" or day == "일":
    print("주말이에요")
else:
    print("평일이에요")
실행 결과
주말이에요
한 줄씩 읽어 봐요
  1. “일”은 “토”와 다르지만 “일”과 같아요.
  2. or는 하나라도 맞으면 참이에요.

바꿔 보기 day = "수"로 바꿔 보세요.

예제 10. 비가 오지 않아요: not

`not`은 맞다/아니다를 뒤집어 줘요.

파이썬 코드
rain = False
if not rain:
    print("산책을 생각해 봐요")
실행 결과
산책을 생각해 봐요
한 줄씩 읽어 봐요
  1. rain은 거짓이에요.
  2. not False 는 True예요.
  3. 따라서 출력문이 실행돼요.

바꿔 보기 rain = True로 바꾸면 아무것도 출력되지 않아요.

8. 내가 입력한 숫자로 판단해요

input으로 받은 글자를 숫자로 바꿔 비교해요.

input()은 키보드에서 입력받아요. 입력한 5도 처음에는 글자이므로, 계산이나 숫자 비교를 하려면 int()로 바꿔요.

예제 11. 내 동전 개수 입력하기

컴퓨터에 동전 수를 직접 입력하는 코드예요.

파이썬 코드
coin = int(input("동전 몇 개? "))
if coin >= 5:
    print("간식 선택 가능")
else:
    print("동전을 더 모아요")
실행 결과
동전 몇 개? 6
간식 선택 가능
한 줄씩 읽어 봐요
  1. “동전 몇 개?”를 묻고 숫자를 입력받아요.
  2. int()가 입력된 글자를 정수로 바꿔요.
  3. 5 이상이면 첫 번째 출력, 아니면 두 번째 출력을 해요.

바꿔 보기 숫자 2를 입력했다면 “동전을 더 모아요”가 나와요. 숫자 대신 글자를 입력하면 오류가 날 수 있어요.

9. 조건 속에 또 조건: 중첩 if

첫 번째 질문이 맞을 때만 안쪽 질문을 해요.

큰 문을 통과해야 작은 문에 갈 수 있다고 생각해 봐요. 들여쓰기는 안쪽으로 갈수록 더 깊어져요.

예제 12. 보물상자 열기

열쇠가 있어야 문을 확인할 수 있어요.

파이썬 코드
key = True
password = False
if key:
    if password:
        print("보물상자 열기!")
    else:
        print("암호가 필요해요")
else:
    print("열쇠를 찾아요")
실행 결과
암호가 필요해요
한 줄씩 읽어 봐요
  1. key가 True라서 바깥 if 안으로 들어가요.
  2. password는 False예요.
  3. 안쪽 else가 실행되어 “암호가 필요해요”가 나와요.

바꿔 보기 password = True 또는 key = False로 바꿔서 세 가지 결과를 확인해 보세요.

10. 한 걸음 더 배우기

기존 자료에 나온 내용을 쉬운 예제로 복습하고 조금 넓혀요.

여기부터는 초등 저학년이라면 선생님과 함께 읽어도 좋아요. 앞의 1~9장을 이해했다면 도전해 봐요.

예제 13. 사이에 있는 숫자: 범위 비교

10부터 20까지인지 한 번에 확인해요.

파이썬 코드
number = 15
if 10 <= number <= 20:
    print("범위 안이에요")
실행 결과
범위 안이에요
한 줄씩 읽어 봐요
  1. 15가 10 이상인지 보아요.
  2. 15가 20 이하인지도 보아요.
  3. 두 조건을 만족하므로 출력해요.

바꿔 보기 number를 9 또는 21로 바꾸면 결과가 나올까요?

예제 14. 목록에 있어요: in

내가 고른 과일이 목록에 있는지 확인해요.

파이썬 코드
fruit = "사과"
if fruit in ["사과", "배", "포도"]:
    print("목록에 있어요")
실행 결과
목록에 있어요
한 줄씩 읽어 봐요
  1. 과일 목록에 “사과”가 있나요?
  2. 있으므로 if 안쪽을 실행해요.

바꿔 보기 fruit를 “바나나”로 바꾸면 아무것도 출력되지 않아요.

예제 15. 빈 상자: 빈 리스트는 거짓

아무 물건도 없으면 빈 상자예요.

파이썬 코드
items = []
if items:
    print("물건이 있어요")
else:
    print("비어 있어요")
실행 결과
비어 있어요
한 줄씩 읽어 봐요
  1. []는 비어 있는 목록(리스트)이에요.
  2. 빈 목록은 조건문에서 거짓처럼 취급해요.
  3. else가 실행돼요.

바꿔 보기 items = ["공"]으로 바꾸면 “물건이 있어요”가 나와요.

예제 16. 한 줄로 선택하기

if-else를 한 줄로 쓰는 방법은 나중에 배워도 좋아요.

파이썬 코드
coin = 5
message = "성공" if coin >= 5 else "다음에"
print(message)
실행 결과
성공
한 줄씩 읽어 봐요
  1. coin이 5 이상인지 묻습니다.
  2. 참이라서 message에 “성공”을 넣어요.
  3. message를 출력해요.

바꿔 보기 읽기 어려우면 4장의 if-else처럼 여러 줄로 써도 괜찮아요.

예제 17. 순서가 바뀌면 결과도 달라져요

큰 기준부터 확인해야 해요.

파이썬 코드
score = 95
if score >= 60:
    print("보통")
elif score >= 90:
    print("우수")
실행 결과
보통
한 줄씩 읽어 봐요
  1. 95는 이미 60 이상이므로 첫 조건이 참이에요.
  2. “보통”을 출력한 뒤 elif는 확인하지 않아요.
  3. 90 이상을 먼저 검사하도록 순서를 바꿔야 “우수”가 나와요.

바꿔 보기 score >= 90을 첫 번째 조건으로 올려 보세요.

실수하기 쉬운 다섯 가지

1. 저장과 비교를 헷갈려요
틀린 코드
if x = 5:
바른 코드
if x == 5:

조건을 비교할 때는 ==를 써요.

2. 콜론을 잊어요
틀린 코드
if x > 5
바른 코드
if x > 5:

조건문 끝에는 :를 적어요.

3. 들여쓰기를 잊어요
틀린 코드
if x > 5:
print("네")
바른 코드
if x > 5:
    print("네")

안쪽 문장은 공백 4칸만큼 들여써요.

4. 숫자 변환을 잊어요
틀린 코드
n = input()
if n >= 5:
바른 코드
n = int(input())
if n >= 5:

input()은 글자를 받으므로 int()가 필요해요.

5. 비교 순서가 달라요
틀린 코드
if score >= 60:
    print("보통")
elif score >= 90:
    print("우수")
바른 코드
if score >= 90:
    print("우수")
elif score >= 60:
    print("보통")

더 높은 기준부터 검사해요.

11. 오늘 배운 것 정리

□ if는 “만약 ~라면”이에요.

□ else는 “그렇지 않다면”이에요.

□ elif는 “다음 조건도 확인해 볼까?”예요.

□ ==는 같은지 비교하고, =는 값을 넣어요.

□ if 끝에는 :를 붙이고, 안쪽 줄은 4칸 들여써요.

□ and는 둘 다, or는 하나라도, not은 반대예요.

말로 설명할 수 있다면 이미 조건문을 잘 이해한 거예요. 이제 문제를 풀어 봐요.
