1. 반복문이 무엇일까요?

같은 일을 여러 번 하는 명령이 반복문이에요.

박수를 세 번 치려면 “짝!”을 세 번 해요. 연필 다섯 자루를 정리할 때도 비슷한 행동을 다섯 번 해요.

컴퓨터에게 같은 일을 여러 번 시키고 싶을 때 반복문을 사용해요. 반복문이 있으면 똑같은 코드를 여러 줄 쓸 필요가 없어요.

박수짝! 짝! 짝! → 같은 행동 3번
계단한 칸, 두 칸, 세 칸 → 차례대로
스티커친구 4명에게 스티커 하나씩 → 4번 반복
기억해요. 반복문은 같은 일을 여러 번 하도록 도와줘요.

2. for: 정한 횟수만큼 반복해요

`for`와 `range()`로 몇 번 반복할지 정해요.

for는 “하나씩 차례대로”라는 뜻이에요. range(3)은 0, 1, 2, 이렇게 숫자 3개를 만들어 줘요.

따라서 for i in range(3): 아래의 들여쓴 문장을 3번 실행해요. i는 지금 몇 번째 숫자인지 담는 이름표예요.

약속: : 뒤 줄은 공백 4칸을 들여써요. 오른쪽으로 들어간 부분만 반복해요.

코드읽는 방법
for하나씩 차례대로
i in range(3)i에 0, 1, 2를 차례대로 넣기
print()화면에 출력하기
:반복할 일을 시작해요
공백 4칸반복문 안쪽의 일이에요

예제 1. 박수를 세 번 쳐요

박수를 세 번 치듯 글자를 세 번 보여 줘요.

파이썬 코드
for i in range(3):
    print("짝!")
실행 결과
짝!
짝!
짝!
한 줄씩 읽어 봐요
  1. range(3)은 0, 1, 2를 만들어요.
  2. 첫 번째 숫자 0일 때 “짝!”을 보여 줘요.
  3. 다음 숫자 1일 때 또 “짝!”을 보여 줘요.
  4. 마지막 숫자 2일 때 한 번 더 보여 줘요. 모두 3번이에요.

바꿔 보기 range(3)을 range(5)로 바꿔 보면 “짝!”은 몇 줄일까요?

예제 2. 친구에게 네 번 인사해요

같은 인사를 네 번 해요.

파이썬 코드
for turn in range(4):
    print("안녕하세요")
실행 결과
안녕하세요
안녕하세요
안녕하세요
안녕하세요
한 줄씩 읽어 봐요
  1. range(4)는 0, 1, 2, 3이에요.
  2. 숫자가 네 개이므로 print가 네 번 실행돼요.
  3. turn이라는 이름표가 매번 다음 숫자를 받아요.

바꿔 보기 range(4)를 range(2)로 바꿔 보세요.

직접 체험 1. 박수를 몇 번 칠까요?

짝! · 짝! · 짝!

range(3)는 0, 1, 2를 만들어요. 따라서 3번 출력돼요.

실행되는 코드
for i in range(3):
    print("짝!")

인쇄에서는 range(0) = 0번, range(3) = 3번, range(5) = 5번으로 기억해요.

3. range(): 숫자를 차례대로 불러요

반복하면서 숫자도 화면에 보여 줄 수 있어요.

range(5)는 0부터 4까지예요. 처음 숫자를 1로 하고 싶다면 range(1, 6)이라고 써요.

아주 중요한 약속: range(시작, 끝)의 끝 숫자는 포함하지 않아요. range(1, 6)은 1, 2, 3, 4, 5예요.

표현만들어지는 숫자반복 횟수
range(3)0, 1, 23번
range(1, 4)1, 2, 33번
range(2, 7, 2)2, 4, 63번
range(5, 0, -1)5, 4, 3, 2, 15번

손가락을 펴며 1부터 5까지 세어 봐요.

바꿔 보기 다섯이 아니라 일곱까지 출력하려면 range(1, 8)을 써요.

컴퓨터는 숫자를 0부터 세는 경우가 많아요.

4. range()로 건너뛰거나 거꾸로 세요

세 번째 숫자를 쓰면 얼마나 건너뛸지도 정할 수 있어요.

range(시작, 끝, 간격)으로 써요. 간격이 2이면 두 칸씩 뛰어요.

간격이 -1이면 숫자가 하나씩 작아져요. 음수 간격은 “뒤로 가기”라고 생각해 보세요.

한 줄씩 읽어 봐요
  1. 2에서 시작해요.
  2. 한 번에 2씩 커져요.
  3. 9보다 작은 숫자까지만 나와요. 따라서 8이 마지막이에요.

바꿔 보기 range(1, 10, 2)로 바꾸면 어떤 숫자가 나올까요?

print("출발!")

4

출발!

  1. 5에서 시작해요.
  2. -1씩 작아지므로 5, 4, 3, 2, 1이 나와요.
  3. 끝 숫자 0은 나오지 않아요.
  4. 들여쓰지 않은 “출발!”은 마지막에 딱 한 번 출력돼요.

5. 물건과 글자도 하나씩 꺼내요

숫자 대신 과일이나 글자도 차례로 꺼낼 수 있어요.

반복문은 숫자에만 쓰는 것이 아니에요. 목록(리스트)에 담긴 과일과 글자 속의 알파벳도 하나씩 꺼낼 수 있어요.

바구니 속 과일을 하나씩 불러요.

파이썬 코드

    print(fruit)

사과
배
포도
한 줄씩 읽어 봐요
  1. 목록에 과일 세 가지가 있어요.
  2. fruit에 먼저 사과, 그다음 배, 마지막으로 포도가 들어가요.
  3. print()가 세 번 실행돼요.

바꿔 보기 목록에 "딸기"를 하나 더 넣으면 어떻게 될까요?

  2. letter에 A, B, C가 차례로 들어가요.
  3. 한 글자씩 세 줄이 출력돼요.

6. while: 조건이 맞는 동안 반복해요

`while`은 “~하는 동안 계속”이라는 뜻이에요.

for는 횟수를 정하기 좋고, while은 조건이 참(True)인 동안 계속하기 좋아요.

꼭 기억해요: while 안쪽에서 숫자를 바꿔야 반복이 끝날 수 있어요. 바꾸지 않으면 끝나지 않을 수도 있어요.

무한 반복 주의: 아래처럼 숫자가 바뀌지 않으면 멈추지 않을 수 있어요. n += 1을 빼먹지 마세요.

예제 9. 세 걸음 걷기

한 걸음씩 세면서 세 걸음을 걸어요.

파이썬 코드
step = 1
while step <= 3:
    print("걸음", step)
    step += 1
실행 결과
걸음 1
걸음 2
걸음 3
한 줄씩 읽어 봐요
  1. step은 처음에 1이에요.
  2. 1 <= 3이 맞으므로 “걸음 1”을 출력해요.
  3. step += 1은 숫자를 1 크게 만들어요.
  4. 2, 3에서도 반복하고, step이 4가 되면 조건이 거짓이라 멈춰요.

바꿔 보기 step <= 3을 step <= 5로 바꾸면 몇 걸음일까요?

예제 10. 저금통에 동전 넣기

저금통에 동전 3개가 모일 때까지 반복해요.

파이썬 코드
coin = 0
while coin < 3:
    coin += 1
    print("동전", coin)
실행 결과
동전 1
동전 2
동전 3
한 줄씩 읽어 봐요
  1. coin을 0개로 시작해요.
  2. 3개보다 적으면 동전을 하나 더해요.
  3. 1개, 2개, 3개가 되었을 때 차례로 출력해요.
  4. coin이 3이면 3 < 3이 거짓이라 반복을 끝내요.

바꿔 보기 동전 5개를 모으고 싶다면 coin < 5로 바꿔요.

직접 체험 2. 동전을 몇 개까지 모을까요?

동전 1 → 동전 2 → 동전 3

0개에서 시작해 3개가 되면 멈춰요.

실행되는 코드
coin = 0
while coin < 3:
    coin += 1
    print("동전", coin)

while은 조건이 거짓이 되는 순간 멈춰요.

7. 반복 중에 조건문도 쓸 수 있어요

반복하는 동안 “만약 ~라면”을 함께 사용할 수 있어요.

if를 반복문 안에 넣으면 특정 숫자일 때만 행동하도록 만들 수 있어요.

들여쓰지 않은 print()는 반복이 끝난 뒤 한 번만 실행돼요.

예제 11. 짝수 번호 카드 찾기

1부터 5까지의 카드 중 짝수만 읽어요.

파이썬 코드
for n in range(1, 6):
    if n % 2 == 0:
        print(n, "짝수")
실행 결과
2 짝수
4 짝수
한 줄씩 읽어 봐요
  1. n은 1, 2, 3, 4, 5가 돼요.
  2. %는 나머지예요. 2로 나누어 나머지가 0이면 짝수예요.
  3. 2와 4에서만 안쪽 print()가 실행돼요.

바꿔 보기 짝수 대신 홀수를 찾으려면 n % 2 == 1로 바꿔요.

예제 12. 공 세 개와 종료 알림

반복 밖의 줄은 한 번만 나와요.

파이썬 코드
for n in range(1, 4):
    print("공", n)
print("끝!")
실행 결과
공 1
공 2
공 3
끝!
한 줄씩 읽어 봐요
  1. range(1, 4)는 1, 2, 3을 만들어요.
  2. “공”은 세 번 나오지만,
  3. 왼쪽으로 나온 “끝!”은 반복이 끝난 뒤 한 번만 나와요.

바꿔 보기 print("끝!")를 공백 4칸 들여쓰면 “끝!”도 세 번 나와요.

8. break와 continue: 멈추거나 건너뛰어요

조금 더 어려운 반복문 명령에 도전해요.

break는 반복을 바로 끝내요. continue는 이번 차례만 건너뛰고 다음 차례로 가요.

아직 어렵다면 예제 13~15는 선생님과 함께 천천히 읽어도 좋아요.

예제 13. 보물상자를 찾으면 멈춰요

세 번째 상자에서 보물을 발견해요.

파이썬 코드
for box in range(1, 6):
    if box == 3:
        print("보물 발견!")
        break
    print("상자", box)
실행 결과
상자 1
상자 2
보물 발견!
한 줄씩 읽어 봐요
  1. 상자 1, 2를 먼저 살펴보고 출력해요.
  2. 상자 3에서는 if가 참이라 “보물 발견!”이 나와요.
  3. break를 만나 반복을 완전히 멈춰요.
  4. 상자 4와 5는 확인하지 않아요.

바꿔 보기 보물이 4번 상자에 있다면 box == 4로 바꿔요.

예제 14. 비 오는 날은 건너뛰어요

3일째는 산책하지 않고 다음 날로 넘어가요.

파이썬 코드
for day in range(1, 6):
    if day == 3:
        continue
    print("산책", day)
실행 결과
산책 1
산책 2
산책 4
산책 5
한 줄씩 읽어 봐요
  1. day가 1, 2일 때 산책을 출력해요.
  2. day가 3일 때 continue를 만나 print를 건너뛰어요.
  3. 4, 5일 때는 다시 산책을 출력해요.

바꿔 보기 day == 2로 바꾸면 2일째가 건너뛰어져요.

예제 15. while에서 목표를 이루면 멈춰요

언제 끝날지 정해지지 않은 반복도 break로 끝낼 수 있어요.

파이썬 코드
level = 1
while True:
    print("단계", level)
    if level == 3:
        break
    level += 1
실행 결과
단계 1
단계 2
단계 3
한 줄씩 읽어 봐요
  1. while True는 조건이 계속 참이에요.
  2. level이 1, 2일 때는 숫자를 하나씩 키워요.
  3. 3이 되면 break를 만나 멈춰요.
  4. 주의: break가 없다면 이 예제는 끝나지 않을 수 있어요.

바꿔 보기 level == 3을 level == 4로 바꿔 보세요.

9. 반복하면서 모으고, 두 번 반복해요

합계와 겹친 반복문을 맛보아요.

숫자를 계속 더할 때는 total += n을 쓸 수 있어요. 반복문 안에 또 반복문을 넣는 것도 가능해요.

예제 16. 1부터 4까지 더하기

동전 1개, 2개, 3개, 4개를 차례로 더해요.

파이썬 코드
total = 0
for n in range(1, 5):
    total += n
print("합:", total)
실행 결과
합: 10
한 줄씩 읽어 봐요
  1. 처음 합계는 0이에요.
  2. 1을 더하면 1, 2를 더하면 3이 돼요.
  3. 3을 더하면 6, 4를 더하면 10이에요.
  4. 반복 바깥의 print()가 최종 합 10을 보여 줘요.

바꿔 보기 1부터 5까지 더하려면 range(1, 6)으로 바꾸세요.

예제 17. 교실 책상 2줄 × 3칸

한 줄씩 읽어 봐요
  1. 바깥 반복은 1번째 줄, 2번째 줄을 골라요.
  2. 안쪽 반복은 매 줄마다 1, 2, 3번 칸을 골라요.
  3. 따라서 총 2 × 3 = 6번 출력돼요.

바꿔 보기 3줄 × 2칸으로 바꾸려면 바깥은 range(1, 4), 안쪽은 range(1, 3)이에요.

10. 반복문 미니게임과 자주 하는 실수

지금까지 배운 내용을 작게 합쳐 봐요.

실제로는 반복문 안에 조건문을 넣고, 점수도 올려요. 모든 줄을 한 번에 외우지 말고 위에서부터 차례로 따라 읽어 봐요.

예제 18. 홀수 차례에 별 모으기

1~5번째 차례 중 홀수 차례에 별 하나를 받아요.

파이썬 코드
stars = 0
for turn in range(1, 6):
    if turn % 2 == 1:
        stars += 1
        print("별", stars)
실행 결과
별 1
별 2
별 3
한 줄씩 읽어 봐요
  1. 1번째 차례에서 별 하나를 얻어요.
  2. 2번째 차례에서는 if가 거짓이라 건너뛰어요.
  3. 3번째에 별 두 개, 5번째에 별 세 개가 돼요.

바꿔 보기 별을 짝수 차례에만 받으려면 turn % 2 == 0으로 바꿔요.

자주 하는 실수 다섯 가지

1. range의 끝을 포함한다고 생각해요
틀린 코드
for n in range(1, 5):
    print(n)  # 5도 나올까?
바른 코드
for n in range(1, 6):
    print(n)

1~5를 출력하려면 끝에 6을 써야 해요.

2. 콜론을 빼먹어요
틀린 코드
for i in range(3)
    print("짝")
바른 코드
for i in range(3):
    print("짝")

for나 while 조건 끝에는 :를 붙여요.

3. 들여쓰기를 빼먹어요
틀린 코드
for i in range(3):
print("짝")
바른 코드
for i in range(3):
    print("짝")

반복할 줄은 공백 4칸 들여써요.

4. while에서 숫자를 바꾸지 않아요
틀린 코드
n = 1
while n <= 3:
    print(n)
바른 코드
n = 1
while n <= 3:
    print(n)
    n += 1

숫자를 바꾸지 않으면 조건이 계속 참이라 반복이 끝나지 않아요.

5. break와 continue를 헷갈려요
틀린 코드
for n in range(1, 5):
    if n == 2:
        break
    print(n)
바른 코드
for n in range(1, 5):
    if n == 2:
        continue
    print(n)

2만 건너뛰려면 break가 아니라 continue를 써요.

11. 오늘 배운 것 정리

□ for는 하나씩 차례대로 반복해요.

□ range(3)은 0, 1, 2를 만들고, 반복은 3번이에요.

□ range(1, 6)은 1~5까지! 끝의 6은 포함하지 않아요.

□ while은 조건이 참인 동안 반복해요.

□ while 안에서는 숫자를 바꾸는 일을 꼭 확인해요.

□ break는 멈춤, continue는 이번 차례만 건너뛰기예요.

□ 안으로 들여쓴 코드만 반복돼요.
