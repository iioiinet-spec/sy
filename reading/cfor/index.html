1. 반복문은 무엇일까요?

같은 일을 여러 번 시키는 명령을 반복문이라고 해요.

친구에게 네 번 인사한다면 똑같은 인사를 네 번 해야 해요. 컴퓨터에도 같은 일을 여러 번 시킬 수 있어요.

C언어의 반복문에는 for, while, do-while이 있어요. 먼저 정해진 횟수만큼 반복하는 for부터 시작해요.

박수짝! 짝! 짝! → 같은 행동 3번
계단1칸, 2칸, 3칸 → 숫자 세기
동전동전 3개가 모일 때까지 넣기 → 목표까지 반복
기억해요! 반복문은 같은 일을 여러 번 실행해요.

2. for: 정한 횟수만큼 반복해요

for는 시작·조건·변화를 적고 차례로 반복해요.

C언어는 for (시작; 조건; 변화) { 반복할 일 }처럼 써요. 처음에는 for (int i = 0; i < 3; i++)를 0부터 시작하고, 3보다 작은 동안, 1씩 더하기라고 읽으면 돼요.

printf()는 화면에 글자를 보여 줘요. \n은 줄을 바꾸는 약속이고, ;는 명령의 끝을 표시해요.

기본 틀: 위에 #include <stdio.h>를 쓰고, int main(void) {에서 시작해 마지막에 return 0;과 }로 끝내요. 모든 예제는 그대로 복사해 실행할 수 있어요.

코드/기호읽는 방법
#include <stdio.h>printf를 사용할 준비
int main(void) {프로그램 시작
for (시작; 조건; 변화)시작하고, 조건이 맞는 동안, 숫자를 바꾸며 반복
i++i를 1 키우기
printf("짝!\n");글자 출력하고 줄 바꾸기
{ }반복할 문장 묶기
return 0;프로그램 마치기
소리 내어 읽기: for (int i = 0; i < 3; i++)는 “i는 0에서 시작, 3보다 작은 동안, 매번 1씩 늘리기”예요.

예제 1. 박수를 세 번 쳐요

박수 세 번을 C언어로 나타내요.

C언어 코드 · 그대로 복사해 실행 가능
#include <stdio.h>

int main(void) {
    for (int i = 0; i < 3; i++) {
        printf("짝!\n");
    }
    return 0;
}
실행 결과
짝!
짝!
짝!
한 줄씩 읽어 봐요
  1. 처음 i는 0이에요.
  2. 0 < 3은 참이라 “짝!”을 출력해요.
  3. i++로 i를 1 크게 하고 다시 조건을 확인해요.
  4. i가 0, 1, 2일 때 실행하고 3이 되면 끝나요.

바꿔 보기 i < 3을 i < 5로 바꾸면 몇 번 출력할까요?

3. 0부터, 또는 1부터 숫자를 세요
시작 숫자와 마지막에 검사할 조건을 살펴봐요.
int n = 1은 처음 숫자를 1로 정한다는 뜻이에요. n <= 5는 n이 5보다 작거나 같을 동안이에요.
<는 작다, <=는 작거나 같다예요. < 5는 5를 포함하지 않지만, <= 5는 5를 포함해요.
반복 조건출력 숫자횟수


n = 0; n < 3; n++0, 1, 23번


n = 1; n <= 3; n++1, 2, 33번


n = 2; n <= 6; n += 22, 4, 63번


n = 3; n >= 1; n--3, 2, 13번

5. 반복할 곳은 중괄호로 정해요
{ } 안쪽은 여러 번, 바깥쪽은 한 번 실행돼요.
C언어는 중괄호 { }로 반복할 범위를 구분해요. 들여쓰기는 읽기 쉽게 만드는 것이고, 실제 범위는 중괄호로 결정돼요.
반복 변수 이름은 i, n, turn처럼 바꿀 수 있어요. 한 글자를 저장하는 char는 심화 예제로 살펴볼게요.

6. while: 조건이 맞는 동안 반복해요
while은 참인 동안 계속 반복해요.
while (조건) { ... }은 조건을 먼저 확인하고 참이면 중괄호 안을 실행해요.
꼭 기억해요. while 안에서 숫자를 바꾸는 일을 빼먹으면 반복이 끝나지 않을 수 있어요.
무한 반복 주의: while 안에서 step++;처럼 값을 바꾸어야 끝날 수 있어요. 코드를 실행하기 전에 확인해요.
예제 9. 세 걸음 걸어요
세 걸음이 될 때까지 하나씩 걸어요.
C언어 코드 · 그대로 복사해 실행 가능
#include <stdio.h>

int main(void) {
    int step = 1;
    while (step <= 3) {
        printf("걸음 %d\n", step);
        step++;
    }
    return 0;
}
실행 결과
걸음 1
걸음 2
걸음 3
한 줄씩 읽어 봐요
  1. 처음 step은 1이에요.
  2. 1, 2, 3에서는 step <= 3이 참이에요.
  3. step++로 매번 숫자를 하나씩 키워요.
  4. step이 4가 되면 반복이 끝나요.
바꿔 보기 step <= 3을 step <= 5로 바꾸면 다섯 걸음이에요.

7. do-while: 먼저 한 번, 그다음 확인해요
do-while은 한 번 실행하고 조건을 확인해요.
while은 조건 먼저, do-while은 실행 먼저라는 차이가 있어요.
do { ... } while (조건);처럼 마지막에 세미콜론 ;이 꼭 필요해요.
예제 11. 세 번 인사하는 do-while
인사를 먼저 한 번 하고, 계속할지 확인해요.
C언어 코드 · 그대로 복사해 실행 가능
#include <stdio.h>

int main(void) {
    int hello = 1;
    do {
        printf("인사 %d번\n", hello);
        hello++;
    } while (hello <= 3);
    return 0;
}
실행 결과
인사 1번
인사 2번
인사 3번
한 줄씩 읽어 봐요
  1. do 안쪽을 먼저 실행해요.
  2. hello를 1 크게 만든 다음 조건을 확인해요.
  3. hello가 4가 되면 4 <= 3은 거짓이라 끝나요.
바꿔 보기 hello <= 3을 hello <= 2로 고쳐 보세요.
예제 12. 조건이 틀려도 한 번은 실행해요
이미 숫자가 커도 do-while은 먼저 한 번 출력해요.

#include <stdio.h>

int main(void) {
    int count = 5;
    do {
        printf("한 번 실행!\n");
        count++;
    } while (count < 3);
    return 0;
}
실행 결과
한 번 실행!
한 줄씩 읽어 봐요
  1. count는 처음부터 5예요.
  2. do 안쪽의 문장을 먼저 실행해요.
  3. count가 6이 된 뒤 6 < 3을 검사하면 거짓이에요.
  4. 거짓이어도 첫 번째 실행 한 번은 있었어요.
바꿔 보기 같은 조건을 while로 썼다면 한 번도 실행하지 않아요.
8. if · break · continue를 함께 써 봐요
반복하다가 필요한 숫자만 골라내거나 멈춰요.
if는 “만약”, break는 “반복을 완전히 멈춤”, continue는 “이번 차례만 건너뛰기”예요.
어려운 부분이므로 선생님과 함께 손가락으로 한 줄씩 따라가 보세요.
예제 13. 짝수 카드만 보여 줘요
숫자 카드 1~5 중 짝수만 골라요.
C언어 코드 · 그대로 복사해 실행 가능
#include <stdio.h>

int main(void) {
    for (int n = 1; n <= 5; n++) {
        if (n % 2 == 0) {
            printf("%d 짝수\n", n);
        }
    }
    return 0;
}
실행 결과
2 짝수
4 짝수
한 줄씩 읽어 봐요
  1. %는 나머지를 구하는 기호예요.
  2. n을 2로 나눠 나머지가 0이면 짝수예요.
  3. 1, 3, 5에서는 출력하지 않아요.
바꿔 보기 n % 2 == 1로 바꾸면 홀수 카드를 고를 수 있어요.
예제 14. 보물을 찾으면 멈춰요
3번 상자에서 보물을 발견해요.
C언어 코드 · 그대로 복사해 실행 가능
#include <stdio.h>

int main(void) {
    for (int box = 1; box <= 5; box++) {
        if (box == 3) {
            printf("보물 발견!\n");
            break;
        }
        printf("상자 %d\n", box);
    }
    return 0;
}
실행 결과
상자 1
상자 2
보물 발견!
한 줄씩 읽어 봐요
  1. 상자 1, 2는 그대로 출력해요.
  2. 3이 되면 보물을 찾고 break를 만나요.
  3. break가 반복 전체를 끝내므로 4, 5는 확인하지 않아요.
바꿔 보기 보물을 4번 상자에 숨기려면 box == 4로 바꿔요.

10. 별 모으기 게임과 실수 고치기

1~5번째 차례 중 홀수 차례에만 별을 얻는 게임을 만들어 봐요.
모든 줄을 암기하지 말고 시작 → 조건 검사 → 출력 → 숫자 변화 순서로 따라 읽어요.
예제 18. 홀수 차례에 별 모으기
1, 3, 5번째에 별을 하나씩 받아요.
C언어 코드 · 그대로 복사해 실행 가능
#include <stdio.h>

int main(void) {
    int stars = 0;
    for (int turn = 1; turn <= 5; turn++) {
        if (turn % 2 == 1) {
            stars++;
            printf("별 %d개\n", stars);
        }
    }
    return 0;
}
실행 결과
별 1개
별 2개
별 3개
한 줄씩 읽어 봐요
  1. turn이 1일 때 별이 1개가 돼요.
  2. 2일 때는 조건이 거짓이라 출력하지 않아요.
  3. 3일 때 별 2개, 5일 때 별 3개가 돼요.
바꿔 보기 짝수 차례마다 얻으려면 turn % 2 == 0으로 바꿔요.
자주 하는 실수 다섯 가지
1. 반복이 한 번 더 또는 덜 돼요
틀린 코드
for (int i = 1; i < 3; i++) {
    printf("짝\n");
}
고친 코드
for (int i = 1; i <= 3; i++) {
    printf("짝\n");
}
1, 2, 3을 세려면 3을 포함하는 <=가 필요해요.
2. 숫자를 바꾸지 않아 끝나지 않아요
틀린 코드
int n = 1;
while (n <= 3) {
    printf("%d\n", n);
}
고친 코드
int n = 1;
while (n <= 3) {
    printf("%d\n", n);
    n++;
}
while에서 숫자를 바꾸지 않으면 계속 반복될 수 있어요.
3. do-while 끝의 ;를 빼먹어요
틀린 코드
do {
    printf("안녕\n");
} while (0)
고친 코드
do {
    printf("안녕\n");
} while (0);
do-while은 끝의 세미콜론을 반드시 적어요.
4. 중괄호 밖에 출력문을 두었어요
틀린 코드
for (int i = 0; i < 3; i++) {
}
printf("짝\n");
고친 코드
for (int i = 0; i < 3; i++) {
    printf("짝\n");
}
반복시키려는 문장을 { } 안쪽에 놓아요.
5. break와 continue를 헷갈려요
틀린 코드
for (int i = 1; i <= 4; i++) {
    if (i == 2) break;
    printf("%d\n", i);
}
고친 코드
for (int i = 1; i <= 4; i++) {
    if (i == 2) continue;
    printf("%d\n", i);
}
2만 건너뛰고 3, 4는 계속하려면 continue예요.
11. 오늘 배운 것 정리
□ for는 시작 → 조건 → 실행 → 변화 순으로 진행해요.
□ for (int i = 0; i < 3; i++)는 3번 반복해요.
□ <는 같은 숫자를 포함하지 않고, <=는 포함해요.
□ while은 조건을 먼저 확인하고 반복해요.
□ do-while은 먼저 한 번 실행하고 조건을 확인해요.
□ break는 바로 멈춤, continue는 이번 차례만 건너뛰기예요.
□ C언어의 { } 안쪽에 반복할 내용을 넣고, ;를 빠뜨리지 않아요.
