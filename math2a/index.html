1√2 는 정말 분수가 아닐까무리수 · ★★★
정답 기약분수라는 가정에 모순이 생기므로, √2 는 분수로 나타낼 수 없다 (무리수)
√2 = p/q (p, q는 서로소인 자연수)라 가정하자. 양변 제곱 : 2 = p²/q² → p² = 2q² (1) p²이 짝수 → p도 짝수. ※ p가 홀수면 p²도 홀수이므로. (2) p = 2k 로 두면 (2k)² = 2q² → 4k² = 2q² → q² = 2k² 같은 이유로 q²이 짝수 → q도 짝수. (3) p와 q가 둘 다 짝수 → 2로 약분된다. 그런데 처음에 서로소(기약분수)라고 했으므로 모순! ⇒ 가정이 틀렸다. √2 는 분수로 나타낼 수 없다.
토론거리 답√4 로 같은 시도를 하면 p² = 4q² → p = 2q 가 되어 모순이 생기지 않습니다. p/q = 2 라는 멀쩡한 분수가 나오지요. 즉 모순이 나지 않는다는 것 자체가 “유리수”라는 증거입니다.
토론 유도“p²이 짝수면 왜 p도 짝수인가?”에서 학생들이 자주 막힙니다. 홀수 × 홀수 = 홀수임을 먼저 확인시키세요.
자주 하는 오답 ① 계산기로 1.41421…를 보여 주며 “안 끝나니까 무리수”라고 함 → 관찰은 증명이 아닙니다. ② 서로소 조건을 빠뜨려 모순을 못 찾음. 이 조건이 증명의 심장임을 강조하세요.

2연속한 자연수의 합수의 성질 · ★★★
정답 (1) 5가지  ·  (2) 64는 불가능 — 2의 거듭제곱이기 때문
45 = 22+23 = 14+15+16 = 7+8+9+10+11 = 5+6+7+8+9+10 = 1+2+…+9 첫 수 a, 개수 k 일 때 합 = ka + k(k−1)/2 = N 양변 2배 : 2N = k(2a + k − 1) 여기서 k 와 (2a+k−1) 는 하나가 홀수면 다른 하나는 짝수이다. (k가 짝수면 2a+k−1은 홀수, k가 홀수면 2a+k−1은 짝수) ⇒ 2N 은 반드시 홀수 인수를 갖는다. 64의 경우 : 2N = 128 = 2⁷ → 1 말고는 홀수 인수가 없다 ⇒ 불가능 (k=1은 자기 자신 하나이므로 '연속한 합'으로 치지 않음)
규칙N의 1을 제외한 홀수 약수의 개수가 곧 표현 가능한 가짓수입니다. 45 = 3²×5 의 홀수 약수는 1,3,5,9,15,45 → 1을 빼면 5가지 ✓
토론 유도먼저 1~20을 나눠 조사시키고 “안 되는 수”를 모으게 하세요. 1, 2, 4, 8, 16이 나오면 학생들이 스스로 “2의 거듭제곱!”을 발견합니다.
자주 하는 오답 45에서 2~3가지만 찾고 멈춤. — k(개수)를 1부터 차례로 넣어 보는 체계적 탐색을 안내하세요.
3종이를 접었더니피타고라스 · ★★
정답 (1) 접으면 대응점까지 거리가 같아지므로  ·  (2) 넓이 75/4 = 18.75 cm²
(1) 접는다는 것은 접는 선을 대칭축으로 D와 B를 포갠다는 뜻이다. 접는 선 위의 모든 점은 D까지와 B까지의 거리가 같으므로, 접는 선은 곧 선분 BD의 수직이등분선이다. (2) 접는 선이 변 AD와 만나는 점을 E라 하자. ED = EB = x 라 두면 AE = 8 − x. 직각삼각형 ABE 에서 (∠A = 90°) AB² + AE² = BE² 6² + (8 − x)² = x² 36 + 64 − 16x + x² = x² 100 = 16x → x = 25/4 = 6.25 겹쳐진 삼각형은 밑변 BE(= x), 높이 AB(= 6)인 삼각형이므로 넓이 = (1/2) × 25/4 × 6 = 75/4 = 18.75 cm²
검산AE = 8 − 6.25 = 1.75, 6² + 1.75² = 36 + 3.0625 = 39.0625 = 6.25² ✓
자주 하는 오답 겹친 부분을 대각선 BD로 자른 절반(넓이 24)으로 착각. — 실제로 접으면 이등변삼각형이 되지 절반이 되지 않습니다. 종이를 직접 접어 보게 하는 것이 가장 확실합니다.

4울타리로 넓이를 최대로이차함수 · ★★
정답 (1) S = x(40 − 2x)  ·  (2) x = 10m, 최대 넓이 200 m²  ·  (3) 100 m² (10×10 정사각형)
담장과 수직인 두 변이 각각 x, 담장과 평행한 변이 40 − 2x S = x(40 − 2x) = −2x² + 40x = −2(x − 10)² + 200 → x = 10 일 때 최댓값 200 (이때 가로 = 40 − 20 = 20m) 즉 가로 : 세로 = 20 : 10 = 2 : 1 ← 정사각형이 아니다! (3) 담장을 못 쓰면 둘레가 40이므로 가로+세로 = 20 S = x(20 − x) = −(x − 10)² + 100 → x = 10, 최대 100 (정사각형)
왜 차이가 나나담장을 쓰면 한 변의 비용이 공짜이므로 그 방향으로 더 길게 만드는 것이 이득입니다. 그래서 담장과 평행한 변이 두 배가 됩니다.
토론 유도x = 5, 10, 15를 대입해 표를 만들게 한 뒤 그래프를 그리게 하세요. 위로 볼록한 포물선의 꼭짓점이 답임을 눈으로 확인합니다.
자주 하는 오답 “넓이가 최대면 무조건 정사각형”이라고 답함(100 m²). — 조건이 둘레 일정일 때만 성립하는 성질임을 짚어 주세요.
5두 사분원이 겹친 부분부채꼴 · ★★★
정답 (1) 아래 변에서 2√3 cm ≈ 3.46cm  ·  (2) 16π/3 − 4√3 ≈ 9.83 cm²
(1) 두 중심을 A(왼쪽 아래), B(오른쪽 아래), 교점을 P라 하자. PA = PB = 4, AB = 4 → 삼각형 PAB 는 한 변이 4인 정삼각형! 따라서 P의 높이 = 정삼각형의 높이 = (√3/2)×4 = 2√3 (2) 겹친 부분 = 부채꼴 A-PB + 부채꼴 B-PA − 정삼각형 PAB 정삼각형이므로 두 부채꼴의 중심각은 모두 60° 부채꼴 하나 = π×4² × 60/360 = 8π/3 정삼각형 = (√3/4) × 4² = 4√3 겹친 부분 = 2 × (8π/3) − 4√3 = 16π/3 − 4√3 ≈ 16.755 − 6.928 = 9.83
왜 빼는가두 부채꼴을 그냥 더하면 가운데 정삼각형 부분이 두 번 세어집니다. 그래서 한 번 빼 줍니다. (포함–배제)
토론 유도“두 반지름과 중심 사이 거리가 모두 4”라는 점에서 정삼각형을 발견하는 것이 이 문제의 전부입니다. 먼저 PA, PB, AB의 길이를 각각 적어 보게 하세요.

6같은 생일인 사람이 있을까확률 · ★★★
정답 약 50.7 % — 절반이 넘는다
직접 세면 경우가 너무 많으므로 여사건(모두 다른 생일)을 먼저 구한다. P(모두 다름) = (365/365) × (364/365) × (363/365) × … × (343/365) = 약 0.4927 P(적어도 두 명 같음) = 1 − 0.4927 = 0.5073 → 약 50.7% 사람 수별 확률 : 10명 11.7% / 20명 41.1% / 23명 50.7% / 30명 70.6% / 50명 97.0%
직관이 어긋나는 이유“나와 생일이 같은 사람”을 떠올리면 22번만 비교하는 셈입니다. 그러나 실제로는 아무 두 사람끼리 비교하므로 23 × 22 ÷ 2 = 253가지 짝이 생깁니다. 253번의 기회라면 50%도 이상하지 않습니다.
토론 유도먼저 예상값을 손들어 투표하게 한 뒤 계산 결과를 공개하세요. 교실 인원으로 실제 조사를 해 보는 것도 효과적입니다(30명 학급이면 70% 확률로 성공).
자주 하는 오답 23/365 ≈ 6% 라고 답함. — 이것은 “특정한 하루에 생일인 사람이 있을 확률”에 가까운 계산입니다. 문제와 무엇이 다른지 비교해 주세요.
7두 사람은 언제 만날까일차함수 · ★
정답 (1) 1시간 뒤 4km 지점  ·  (2) y = 4x 와 y = −8x + 12 의 교점 (1, 4)  ·  (3) 3시간 뒤 24km 지점
(1)(2) A의 위치 : y = 4x B의 위치 : y = 12 − 8x (마주 봄) 4x = 12 − 8x → 12x = 12 → x = 1 (시간), y = 4 (km) ※ 거리 12km를 서로 다가가는 속력의 합 (4+8=12)로 나눈 것과 같다. (3) B가 같은 방향(멀어지는 쪽)으로 가면 두 그래프는 평행하지 않고 A가 더 느리므로 A는 B를 따라잡을 수 없다. 반대로 B가 A를 뒤쫓는 상황(B가 0km 쪽에서 출발)이라면 12 ÷ (8 − 4) = 3시간 뒤, 8 × 3 = 24km 지점에서 만난다.
토론 유도“만난다 = 그래프가 교차한다”는 대응을 말로 설명하게 하세요. 기울기의 부호가 마주 봄/같은 방향을 결정한다는 점도 짚어 줍니다.

8바꾸는 것이 유리할까조건부 상황 · ★★
정답 (1) 1/3  ·  (2) 유지 1/3, 바꿈 2/3 → 바꾸는 것이 두 배 유리
처음 고른 문이 정답일 확률은 1/3, 나머지 두 문에 있을 확률은 2/3. 사회자가 문을 열어도 처음 선택의 확률 1/3은 변하지 않는다. (사회자는 정답을 알고 있어서 반드시 염소 문을 열기 때문) 따라서 나머지 2/3이 남은 문 하나에 그대로 몰린다. 세 경우로 확인 (처음에 1번 문을 골랐다고 하자) 자동차가 1번 : 바꾸면 실패 자동차가 2번 : 사회자는 3번을 염 → 바꾸면 성공 자동차가 3번 : 사회자는 2번을 염 → 바꾸면 성공 ⇒ 바꿔서 성공하는 경우가 3가지 중 2가지
토론거리 답문이 100개이고 사회자가 98개를 열어 주면, 바꿀 때 성공 확률은 99/100입니다. 처음에 정답을 찍었을 확률이 1%뿐이었기 때문이지요. 숫자를 키우면 직관이 바로잡힙니다.
토론 유도카드 3장으로 실제 20회 실험을 시켜 보세요. 바꾸기 전략이 대략 13~14회 성공하는 것을 눈으로 보면 논쟁이 정리됩니다.
자주 하는 오답 “문이 2개 남았으니 반반(1/2)”. — 사회자가 정답을 알고 골라서 열었다는 조건이 핵심입니다. 만약 사회자도 모르고 우연히 열었다면 그때는 정말 1/2이 됩니다.
93의 배수 판정은 왜 통할까문자와 식 · ★★
정답 (1) 아래 식  ·  (2) 9는 통함, 7은 통하지 않음  ·  (3) 3의 배수이다
(1) 세 자리 수 = 100a + 10b + c = (99a + 9b) + (a + b + c) = 3(33a + 3b) + (a + b + c) 앞부분은 항상 3의 배수이므로, 전체가 3의 배수인지는 (a+b+c)가 3의 배수인지에만 달려 있다. (2) 99와 9는 9의 배수이기도 하므로 같은 논리가 9에서도 성립한다. 그러나 99는 7의 배수가 아니므로 7에서는 성립하지 않는다. (예: 16 → 1+6=7이지만 16은 7의 배수가 아님) (3) 1234…4950 의 자리 숫자를 모두 더하면 결국 1+2+…+50 을 더한 것과 3으로 나눈 나머지가 같다. (10, 100, … 을 곱해도 나머지는 그대로이므로) 1+2+…+50 = 50×51/2 = 1275, 1275 ÷ 3 = 425 ⇒ 3의 배수
토론 유도“왜 하필 99와 9인가?”를 물어보세요. 10 − 1 = 9, 100 − 1 = 99 처럼 10의 거듭제곱에서 1을 뺀 수가 항상 9의 배수라는 점이 열쇠입니다.
자주 하는 오답 (3)에서 실제로 긴 수를 쓰고 나누려 함. — 자리 숫자의 합만 보면 된다는 (1)의 결론을 그대로 적용하는 것이 문제의 의도입니다.
