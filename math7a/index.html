A1소수 세 쌍둥이정수 · ★★
정답 p = 3 (3, 5, 7) — 유일
p = 3 : 3, 5, 7 모두 소수 ✓ p = 5 : 5, 7, 9 = 3×3 ✗ p = 7 : 7, 9 ✗ p = 11 : 11, 13, 15 ✗ [왜 p = 3 뿐인가] p가 3이 아닌 소수이면 p는 3의 배수가 아니므로 p ≡ 1 또는 2 (mod 3) · p ≡ 1 → p + 2 ≡ 0 (mod 3) → p+2 가 3의 배수 · p ≡ 2 → p + 4 ≡ 0 (mod 3) → p+4 가 3의 배수 어느 경우든 셋 중 하나가 3보다 큰 3의 배수가 되어 소수가 아니다. ⇒ p = 3 만 가능 [일반화] p, p+2, p+4 는 3으로 나눈 나머지가 0, 1, 2 전부를 한 번씩 갖는다.
풀이 핵심“하나씩 대입해 보니 안 되더라”는 증명이 아닙니다. mod 3으로 분류하면 무한히 많은 경우가 단 두 가지로 줄어듭니다.
지도 방법먼저 p = 5, 7, 11, 13 을 대입해 걸리는 수에 동그라미를 치게 하세요. 9, 15, 21 … 이 나오는 것을 보면 학생이 스스로 “3의 배수!”를 발견합니다.
자주 하는 오답 답만 3이라 쓰고 유일성을 설명하지 않음. 경시 서술형에서는 절반만 맞은 답입니다. “다른 p는 왜 안 되는가”를 반드시 쓰게 하세요.

A2뒤집은 수와의 관계정수 · ★★
정답 (1) 50, 61, 72, 83, 94　(2) 8개
두 자리 수를 10a + b (a는 1~9, b는 0~9), 뒤집은 수를 10b + a 라 하자. (1) 차 : (10a + b) − (10b + a) = 9(a − b) = 45 → a − b = 5 (a,b) = (5,0)(6,1)(7,2)(8,3)(9,4) → 50, 61, 72, 83, 94 (2) 합 : (10a + b) + (10b + a) = 11(a + b) = 121 → a + b = 11 (a,b) = (2,9)(3,8)(4,7)(5,6)(6,5)(7,4)(8,3)(9,2) → 8개 ※ a + b = 11 이므로 b ≥ 2, a ≤ 9 → a는 2~9 중 8가지
풀이 핵심차는 항상 9의 배수, 합은 항상 11의 배수입니다. 이 사실만 알면 대부분의 뒤집기 문제가 즉시 풀립니다.
지도 방법“차가 50인 두 자리 수가 있을까?”를 물어보세요. 9의 배수가 아니므로 존재하지 않습니다. 이런 질문이 구조를 각인시킵니다.
자주 하는 오답 (2)에서 b = 0, 1 인 경우까지 세어 10개라 답함. a + b = 11 이면 b는 최소 2입니다(a ≤ 9). 자릿수의 범위를 항상 확인시키세요.
A3팩토리얼 끝의 0정수 · ★★
정답 100! 의 0은 24개, 0이 30개인 최소 n = 125
끝의 0 하나 = 2 × 5 한 쌍. 1~100에는 2가 훨씬 많으므로 5의 개수가 답이다. 5의 배수 : 100 ÷ 5 = 20개 25(=5²)의 배수 : 100 ÷ 25 = 4개 ← 5를 하나 더 갖고 있으므로 추가 125 > 100 이므로 여기까지 합계 20 + 4 = 24개 [0이 30개가 되는 최소 n] n = 120 : 24 + 4 = 28 n = 124 : 24 + 4 = 28 n = 125 : 25 + 5 + 1 = 31 ← 125 = 5³ 이라 한 번에 3개가 늘어난다 0이 29개, 30개인 n은 존재하지 않는다. 30개를 처음 넘어서는 n = 125
풀이 핵심n/5 + n/25 + n/125 + … (몫만 취함)이 공식입니다. 25, 125를 빠뜨리는 것이 최대 실수 요인입니다.
지도 방법“왜 2는 세지 않는가?”를 물어보세요. 2의 개수(97개)가 5의 개수(24개)보다 훨씬 많다는 것을 직접 세어 보게 하면 확실히 이해합니다.
주의 두 번째 물음은 0의 개수가 건너뛰는 구간이 있다는 함정이 있습니다. 125에서 28 → 31로 3계단 뛰므로 “정확히 30개”인 n은 없습니다. 문제 표현을 “처음으로 30개 이상”으로 읽도록 안내하세요.

A4나머지가 두 개 주어질 때정수 · ★★
정답 (1) 123　(2) 35마다
조건이 센 7부터 나열한다. 7로 나누어 4 남는 수 : 4, 11, 18, 25, 32, 39, 46, … 그중 5로 나누어 3 남는 수(끝자리가 3 또는 8) : 18? → 18÷5 = 3…3 ✓ → 가장 작은 자연수 해는 18 5와 7의 최소공배수가 35 이므로 해는 35마다 반복된다. 18, 53, 88, 123, 158, … 세 자리 수 중 가장 작은 것 = 123 [검산] 123 ÷ 5 = 24…3 ✓, 123 ÷ 7 = 17…4 ✓
풀이 핵심두 조건을 동시에 보려 하지 말고 한쪽을 먼저 나열한 뒤 거르는 것이 정석입니다. 어느 쪽부터 할지는 나누는 수가 큰 쪽이 유리합니다(후보가 적으므로).
확장나누는 수들이 서로소이면 해는 반드시 존재하고 최소공배수마다 반복됩니다(중국인의 나머지 정리). 서로소가 아니면 해가 없을 수도 있습니다.
자주 하는 오답 18을 찾고 그대로 답함(세 자리 조건 놓침). 또는 주기를 5+7 = 12로 잘못 씀. — 최소공배수임을 강조하고, 18 + 35 = 53이 실제로 두 조건을 만족하는지 검산시키세요.
A5제곱수가 되게 하라정수 · ★★★
정답 n = 4 (4² + 20 = 36 = 6²)
n² + 20 = m² 라 하면 m² − n² = 20 → (m − n)(m + n) = 20 m − n 과 m + n 은 홀짝이 같아야 한다. (합) + (차) = 2m 이 짝수이므로 둘 다 짝수이거나 둘 다 홀수. 그런데 곱이 20(짝수)이므로 둘 다 짝수여야 한다. 20 = (짝수)×(짝수) : 2 × 10 뿐 (4×5, 1×20, 20×1 등은 홀짝이 다름) m − n = 2, m + n = 10 → m = 6, n = 4 [검산] 4² + 20 = 16 + 20 = 36 = 6² ✓
풀이 핵심제곱수 조건 → 차의 인수분해가 이 유형의 표준 흐름입니다. 무한히 많은 n을 확인할 필요 없이 20의 약수쌍 몇 개만 보면 끝납니다.
지도 방법“왜 홀짝이 같아야 하나?”가 핵심 관문입니다. m − n 과 m + n 의 합이 2m(짝수)라는 점에서 나옵니다. 이 논리를 말로 설명하게 하세요.
자주 하는 오답 20 = 1×20, 4×5 까지 넣어 n을 여러 개 구함. — 각각에서 m, n이 정수가 되는지 실제로 계산시키면(1×20 → m = 10.5) 스스로 걸러 냅니다.

A6이중근호 벗기기대수 · ★★
정답 (1) √5 + √2　(2) √5 − 2
(1) 7 + 2√10 에서 합이 7, 곱이 10인 두 수를 찾는다 → 5와 2 7 + 2√10 = 5 + 2 + 2√(5×2) = (√5 + √2)² ⇒ √(7 + 2√10) = √5 + √2 (≈ 2.236 + 1.414 = 3.650) (2) 4√5 를 2√(?) 꼴로 : 4√5 = 2 × 2√5 = 2√20 9 − 2√20 에서 합이 9, 곱이 20인 두 수 → 5와 4 9 − 2√20 = 5 + 4 − 2√(5×4) = (√5 − √4)² = (√5 − 2)² ⇒ √(9 − 4√5) = √5 − 2 ※ √5 ≈ 2.236 > 2 이므로 양수가 되도록 큰 것에서 작은 것을 뺀다. (2 − √5 는 음수라 오답)
풀이 핵심2√( ) 꼴로 만드는 것이 첫 단계입니다. 계수가 2가 아니면 반드시 고쳐야 합니다.
지도 방법“합이 A, 곱이 B인 두 수”는 이차방정식의 근과 같습니다. 근의 성질을 배운 학생에게는 이 연결을 짚어 주세요.
자주 하는 오답 (2)에서 2 − √5 라고 답함. — 근호를 벗기면 반드시 0 이상이어야 합니다. 계산기로 두 값을 비교하게 하면 즉시 납득합니다.
A7가장 작은 값은 얼마인가대수 · ★★
정답 최솟값 6, 이때 x = 3
x > 0 이므로 √x 를 생각할 수 있다. (√x − 3/√x)² ≥ 0 x − 2·√x·(3/√x) + 9/x ≥ 0 x − 6 + 9/x ≥ 0 ⇒ x + 9/x ≥ 6 등호는 √x = 3/√x, 즉 x = 3 일 때 성립. x = 3 : 3 + 9/3 = 3 + 3 = 6 ✓ [값 확인] x=1 → 10, x=2 → 6.5, x=3 → 6, x=4 → 6.25, x=9 → 10
풀이 핵심제곱은 항상 0 이상이라는 사실 하나로 최솟값이 증명됩니다. 표를 만들어 “6보다 작은 값이 안 나온다”를 관찰하는 것은 증명이 아닙니다.
확장일반적으로 x + a/x ≥ 2√a (x > 0, a > 0)이고 등호는 x = √a 일 때. 이것이 산술–기하평균 부등식의 가장 단순한 형태입니다.
자주 하는 오답 x = 0 또는 음수를 대입해 더 작은 값을 얻음. — x > 0 조건을 놓친 것입니다. x = −3 이면 −6이 되지만 조건 밖임을 확인시키세요.

A8원 밖의 점에서 그은 접선기하 · ★★
정답 (1) 12　(2) 8과 7
(1) 접선은 접점에서 반지름과 수직이므로 직각삼각형이 된다. A9내심이 만드는 각기하 · ★★

A10덮을 수 있을까조합 · ★★★
정답 덮을 수 없다
체스판처럼 검은색과 흰색을 번갈아 칠한다. 8 × 8 = 64칸 → 검정 32, 흰색 32 도미노 하나는 가로든 세로든 반드시 이웃한 두 칸을 덮으므로 항상 검정 1칸 + 흰색 1칸을 덮는다. 따라서 도미노 31개는 검정 31칸 + 흰색 31칸을 덮는다. 그런데 마주 보는 두 모서리(왼쪽 위와 오른쪽 아래)는 같은 색이다. 그 둘을 잘라 내면 남은 것은 검정 30 + 흰색 32 (또는 그 반대) 30 ≠ 31 이므로 덮는 것이 불가능하다.
