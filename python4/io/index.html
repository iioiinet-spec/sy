파이썬 입출력, 왜 배울까요?

정보올림피아드와 코드업 문제는 예제 입력을 정확히 읽고 예제 출력 형식대로 결과를 보여 주는 것에서 시작합니다. print()는 화면에 출력하고, input()은 데이터를 읽습니다.

1. 입력
input() / split()
2. 처리
변수 / 계산 / 반복
3. 출력
print()

학습 순서: 예제 출력을 예측하기 → 단계별 흐름 살펴보기 → 예제 입력 수정 후 결과 확인하기 → 연습문제 풀기 → 퀴즈 확인하기

1차시　1~3장 · print, sep/end, 특수문자
2차시　4~6장 · f-string, input, 숫자 변환
3차시　7~9장 · 몫/나머지, split/map, 리스트
4차시　10~12장 · N줄, 행렬, 온라인 채점

실행 범위 안내: 인터넷 없이 작동하는 교육용 시뮬레이터로, 수록된 12개 예제의 입력값을 바꾸어 결과를 계산합니다. 임의의 파이썬 코드를 실행하지는 않습니다. 본문 예제 코드는 실제 Python으로 검증했습니다.
