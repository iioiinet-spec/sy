01. 반복문의 첫걸음: for

반복문은 같은 일을 정해진 횟수만큼 수행하는 구조입니다. for는 반복할 값을 하나씩 꺼내 실행합니다.

실행 흐름　시작 → 반복할 값 확인 → 반복 본문 실행 → 다음 값으로 이동 → 종료
주의할 점: for 문의 콜론(:)과 들여쓰기는 반복 본문의 범위를 결정합니다.

직접 입력 · 단계 추적

range(1, n+1)는 1부터 n까지 차례로 정수를 만듭니다.

n = int(input())
for i in range(1, n + 1):
    print(i)

02. range()의 시작·끝·간격
range(start, stop, step)에서 stop은 포함되지 않습니다. step은 증가 또는 감소할 수 있습니다.

04. while과 종료 조건
while은 조건식이 참(True)인 동안 반복합니다. 언젠가 조건이 거짓이 되도록 변수의 값이 바뀌어야 합니다.
실행 흐름　조건 검사 → True면 본문 → 변수 변경 → 다시 조건 검사 / False면 종료
주의할 점: 반복 변수 변경을 빠뜨리면 무한 반복이 발생할 수 있습니다.

n = int(input())

05. break: 반복 즉시 중단
break를 실행하면 반복문 전체가 즉시 종료됩니다. 조건에 맞는 첫 항목을 찾을 때 자주 사용합니다.
실행 흐름　i 증가 → 검사 → break를 만나면 곧바로 반복 밖으로
주의할 점: break는 가장 안쪽 반복문 하나만 빠져나갑니다.
